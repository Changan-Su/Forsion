# Agent 总览

在 Forsion 里,Agent 是**长期伙伴**:它有自己的人格、独立的记忆、专属的资料库和工作日志。你可以为不同的事创建不同的 Agent——写作教练、代码搭档、生活管家——它们互不串味。

## 一个 Agent 由什么组成

每个 Agent 在磁盘上就是一个独立文件夹,内容完全透明:

| 组成 | 说明 |
|------|------|
| **配置** | 名字、头像、使用的模型、开放哪些工具、审批档位 |
| **人格(SOUL)** | 一份 Markdown:它是谁、什么口吻、什么原则。写得越具体,角色越立体 |
| **协作说明(HUMAN.md)** | Agent 对你的意见和请求：它希望你怎么配合、需要你补充哪些信息，以及能帮助当前目标的可选学习 |
| **记忆(MEMORY)** | 你告诉它的、纠正它的、要求它的，以及相处中记下的事实。每个 Agent 一份；只在某个项目里成立的另存为项目记忆，见[记忆系统](memory.md) |
| **进化记录(HARNESS.md)** | 它自我进化的内容：自己总结出来的做法、给自己收起的工具和技能 |
| **资料库(Library)** | 你塞给它的参考资料,回答时可随时查阅 |
| **日志(LOG)** | 它替你干过什么,有账可查 |

## 创建与管理

- **界面创建**:在 Agent Space 的左侧名册面板中新建，填写名称与工作指令；创建后直接进入它的档案;
- **装现成的**:「应用市场 → 代理」里是别人调好的 Agent,一键安装,人格与配置一步到位;
- **让 AI 代劳**:直接在对话里说"帮我建一个每天督促我锻炼的教练 Agent",AI 会调用管理工具替你建好;
- **随时调整**:在 Agent Space 或 Tangu 详情中编辑模型、工作指令、技能和工具权限。Agent Space 名册菜单还可设默认、排序和删除 Agent；名册可通过工作台侧栏按钮收起或拖宽，详情始终保持合适的阅读宽度。配置保存后生效。

## 协作说明：HUMAN.md

在 **Agent 详情 → 协作** 中查看长期协作说明；在 **项目详情 → 协作** 中查看这个项目的约定。正文按 Markdown 阅读，支持编辑；「更多操作」中可以查看原文、文件位置和修改历史。项目页还可展开当前 Agent 的长期说明；团队会话分别列出成员。

作用域由内容决定：针对本项目的目标、分工和验收方式写入项目说明；离开本项目仍适用的沟通与协作方式写入 Agent 说明。共享记忆不会合并两个 Agent 的协作说明。

协作说明写的是 **Agent 对你的意见和请求**：它发现怎样配合更顺、哪些信息需要你先给、哪些做法值得你了解。方向是它对你，不是你对它——你对它的纠正和要求不写在这里，而是进它的[记忆](memory.md)。

Agent 可以根据反复出现的协作问题更新说明。更新**立即生效**，聊天中的「协作说明已更新」卡片会展示归属、摘要和依据，可直接查看、修改或撤销。无需点击采纳；下一轮对话会读取最新文件。写入说明不会改变工具权限或审批规则。

编辑草稿会在切换详情页签时保留。若文件同时被其他会话或编辑器修改，保存会提示冲突并保留草稿，需要查看最新内容后合并。撤销仅适用于仍是最新版的那次更新，避免覆盖后续修改。

本功能目前连接本地 Tangu 引擎使用。Agent 文件位于其目录下的 `HUMAN.md`；新项目文件写入所选项目的 `.tangu/HUMAN.md`，兼容已有根目录或 `.forsion/HUMAN.md`。最近 40 次修改历史保留在本机引擎目录，不写入项目仓库；历史保留范围之外的旧卡片仍可打开当前说明，但不可直接撤销。

本地普通会话中的 `manage_human` 每轮均可用，无需重新加载；计划、远程和子代理等边界仍按原规则限制。回归入口 `tangu-agent` 的 `npm run live:harness -- --only human` 覆盖后续自然反馈自动更新，追加 `--human-ui` 验证真实 Electron 卡片与编辑。

## 进化记录：HARNESS.md

在 **Agent 详情 → 成长 → 进化** 中查看。进化记录记录 Agent **自我进化**的内容：它从实际工作中自己总结出来的做法（「读文件回答前先引用原文再下结论」「这类任务先派给谁」），每次对话都会带上。三处的分工：你告诉它、纠正它、要求它的进**记忆**；它对你的意见和请求写在**协作说明**；它自己悟出来的做法写在**进化记录**。

进化记录由 Agent 自己维护。写入**立即生效**，不需要逐条批准；聊天中的「进化记录已更新」卡片会展示改了什么、依据是什么，可以直接撤销。撤销仅适用于仍是最新版的那次更新；条目之后又改过时，到「进化」页里调整。记录只是它的参考，不会改变工具权限或审批档位。

记录有四个来源，都能在「进化」页撤销；前三个不需要你先批准：

- **Agent 自己在对话里写**：它当场意识到一个做法值得保留。
- **后台复盘写入**：开启 Historian 后，后台判官读完一段对话，把 Agent 自己总结或承诺的做法直接记成一条记录（条目上标「后台复盘写入」，并有一条通知）。只有纯文字的工作方法才会直接写入；带网址、行内代码或命令，或提到凭据、审批、权限、系统提示的，一律不直接写，留在候选里等你确认（见下）。你删掉或撤销的后台记录，后台不会再写回来。同一段对话里 Agent 自己已经写过记录时，后台不再替它写，免得同一个做法记两遍。
- **Muse 代为收起**：见 [每周装备巡检](muse.md#每周装备巡检)。
- **你采纳的候选**：见下。

### 候选：有风险的由你逐条确认

「进化」页下方的候选是提名，还不是记录，不会生效。它们分两种：

- **等你确认**（条目上有标记）：带网址、行内代码或命令，或提到凭据、审批、权限、系统提示的。只有你能决定——点**采纳**就写成一条记录（标「你采纳的候选」，可撤销），点**丢弃**就删掉。Agent 复盘时读不到这些；出现时会有一条通知。
- **其余的**：在会话里输入 `/refine`，Agent 会复盘这段对话并决定哪些值得写进记录；你也可以先一步采纳或丢弃。

别的 Agent 转来的装备建议只能由这个 Agent 自己在复盘时采纳（要按它的工具清单核对名字），面板上只能丢弃。候选太长、或记录已满时无法采纳，面板会说明原因。

记录里有一类**装备**条目：Agent 把自己很少用到的工具或技能**收起来**，减少每次请求携带的内容。收起的工具改为按需加载、仍然可用，收起的技能不再出现在技能清单里、按名称仍可使用；撤销或删除这一条就全部恢复。它只能收起，不能给自己增加任何能力——工具黑白名单与技能清单仍以你的设置为准。记忆、协作说明、日志、待办和加载工具这几件不能收起。

本功能目前连接本地 Tangu 引擎使用，文件位于 Agent 目录下的 `HARNESS.md`。本地普通会话中 `manage_harness` 每轮均可用（Coding 预设下按需加载）；计划、远程和子代理等边界仍按原规则限制。不想让某个 Agent 自己改记录，可在它的工具黑名单里关掉 `manage_harness`；关掉后后台复盘也不会直接写入（提名只留在候选里，你仍可以逐条采纳），Muse 的每周巡检也不会替它收起。回归入口 `tangu-agent` 的 `npm run live:harness -- --only harnessopen,equip,refine`。前两个场景的消息点了名（「记一条工作方法」「把这两个工具收起来」），只证接线；`refine` 走的是「问它自己打算坚持什么做法 → 记录里多出一条 → 新会话带上 → 可撤」；平常使用的样子用 `--only realuse`（消息不提任何存储库或工具名，可加 `--usage-db` 用真实用量跑一遍巡检），更新卡在真 Electron 里的样子用 `--only harnessopen --harness-ui`。

## 内置 Agent

- **Arioso** — 默认助手，关注目标、感受与取舍，提供独立判断。
- **Aria** — 关注情绪细节、表达与创造性。
- **Recita** — 检查证据、假设与可行性。
- **Coding** — 聚焦代码与实现。
- **[Muse](muse.md)** — 主动型助理，启用后按配置跟进；活动感知另行开启。

Arioso、Aria、Recita 等常规 Agent 可用于 [TEAM](../chat/group-chat.md)：保存成员与职责，在 `TEAM.md` 写共同约定，用 Team Desk 查看并行工作。English: [TEAM guide](../chat/group-chat.en.md).

## 每个 Agent 各用各的配置

模型、[工具黑白名单与审批档位](../chat/tools-and-approvals.md)都是按 Agent 独立设定的。让"文件整理员"只能动文件、"资讯官"只能联网,权责分明。

## 它是怎么干活的

- **子任务并行** — 一件复杂的事可以拆成几路子任务同时推进,按需传递任务背景，由主 Agent 汇总结果;
- **自我脑暴** — 同一个人格拆成多个视角,各自出主意、互相批评,最后汇总成一个结论;方案选型、写作定调这种"一个角度不够用"的事适合让它这么想;
- **分身模式** — 后台那些顺手的判断,在当前这份完整上下文里就地做掉,不另起一轮对话:看得到全部前情,也更省时间;
- **收尾有交代** — 长任务结束时会说清产物落在哪个路径、叫什么字面名称;交付网页时它会自己看一眼渲染结果再定稿。

干活的过程与产出可以摊在聊天右侧看,见 [Agent Desk 与任务概览](../chat/agent-desk.md)。
