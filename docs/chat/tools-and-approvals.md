# 工具与审批

Tangu 的核心能力是**工具调用**:AI 不只生成文字,还能读写文件、执行命令、搜索网页、管理笔记和日程。权限体系保证它"能干活,但越不了界"。

## 内置工具

大致分几类:

- **文件与命令** — 读写工作区文件、执行终端命令(本地模式);
- **信息获取** — 网页搜索与抓取、读取图片;
- **Forsion 生态** — 操作 Amadeus 笔记、管理日程、发消息到收件箱、创建和配置 Agent;
- **本机集成** — 浏览器自动化、微信收发、桌面操作等(本地模式,部分需要先在设置里配置)。

命令行输出很长时,对话里只贴截断后的片段,完整输出会落成文件并给出路径,要细看照路径打开就行。

## 审批四档

输入框上的审批档决定"动手前问不问你",从紧到松四档:

| 档位 | 含义 |
| --- | --- |
| **询问我批准** | 改文件、跑命令前都先问你(搜索、抓网页、读文件,以及 `ls`、`git status` 这类只读命令不问) |
| **替我批准** | 工作区内可以直接改文件;跑命令、写工作区以外的文件才问你 |
| **完全放行** | 不再询问,不受限地访问网络和你电脑上的文件(`.git` 内部、密钥凭据目录等受保护路径仍然禁写) |
| **自定义** | 按你自己写的规则判定(allow / ask / deny) |

"跑命令"这一档还包括:后台进程、MCP 工具、在你自己的 Chrome 里点按输入,以及插件声明为同档的工具(比如桌面操作)。

自定义档的规则写在 `~/.forsion/config.json`(只装了命令行、没装桌面端时是 `~/.tangu/config.json`)的 `approval` 段:`base` 给一个兜底档,`allow` / `ask` / `deny` 三张表逐条列工具名(`*` 结尾是前缀通配,还能再跟 `:参数前缀`,例如 `run_bash:npm test`)。优先级是 deny > ask > allow > base,一条都没命中就按 base 档处理。改完即时生效,不必重启。

新开的会话会延续你上次用的档位、模型与思考档,不必每次重设。

## 审批卡:动手前先问你

需要点头的操作会弹出审批卡,展示它想干什么:

- **批准** — 执行这一次;
- **本会话总是允许** — 本会话里**这个工具**以后都不再问,放行的是整个工具而不是这一条参数:对跑命令点了它,本会话之后的所有 shell 命令都直接执行。只在当前会话有效,重启应用后也会失效;写工作区以外的文件、以及你在自定义规则里写成「每次问」的操作不吃这一条,仍然每次都问(卡上也不会出现这个按钮);
- **拒绝** — 不执行,AI 会另想办法;
- 部分操作还允许你**修改参数后再批准**(比如改掉命令里的某个路径)。

## 让 Agent 帮你切模型 / 思考档

不必自己去点输入框上的模型与思考药丸,直接跟 AI 说"切到 opus""这题想深一点"就行 —— 它会调用 `update_session_settings` 改**本会话**的模型或思考深度(名字写个大概即可,对不上或有歧义时它会列出候选让你选)。在微信 / Telegram / QQ 通道里没有药丸可点,这是改设置最顺手的办法。

- **要你点头** — 在「询问我批准」「替我批准」档下会弹审批卡,卡上写着它想改成什么和理由;「完全放行」档自动通过,自定义档按你的规则判定;
- **何时生效** — 换模型要等**这一轮回复结束**:之后你发的下一条消息起才用新模型(回复进行中插的话会并进当前这一轮,仍用原模型);思考深度从它的下一次请求起就生效;
- **只改这一个会话** — 你新开会话的默认模型不变。桌面端正停在这个会话上(或在这一轮回复期间切进来、或这一轮就是在桌面端发起的)时,药丸会同步刷新并提示一声;如果是在微信 / Telegram / QQ 里改的、桌面端当时没停在这个会话上,桌面上的药丸可能还停在旧值,回桌面接着聊之前先看一眼药丸;
- **改不了审批档** — 审批档只能由你自己切,AI 不能替自己放宽权限;
- 子任务、团队成员、Muse 与自动化规则里的 AI 用不了它。

## 计划模式

打开计划模式后,AI 先**只读**地调研并给出完整计划。计划看着可行时,可以直接选择**「批准并自动开始执行」**,一步进入动手阶段;也可以先讨论修改再放行。适合大改动、不熟悉的任务,或你想先看看思路的场合。

## 工作范围:可以加额外文件夹

新建会话的工作目录默认落在笔记库的 `Sessions/` 文件夹下,AI 在这轮里产出的文件就存在那里。需要跨目录干活时,可以给它**加额外文件夹**,让同一轮任务同时读写多个目录。加过的文件夹在任务概览卡里逐条列出,随时移除。

## 项目级指令文件

工作目录里的 `AGENTS.md` / `CLAUDE.md` 会被自动读取,当作这个项目的固定规矩。查找方式是从工作目录**逐级向上,到项目根为止**,绝不越过项目根 —— 家目录里的同名文件不会被顺带吃进来。

## `/verify`:跑绿了才算完

在会话里发 `/verify <命令>`,就给这轮任务挂上一条验收命令:AI 收尾前必须把它跑通,不通就继续修。若最后一次仍然失败,结果会**如实标注为失败**,而不是含糊地宣布做完了。

## 每个 Agent 的工具黑白名单

在 Agent 配置里可以为它单独设定**工具白名单 / 黑名单**:勾选即允许。给"纯聊天"的角色关掉所有动手能力,给自动化专用的 Agent 只留必要工具,互不越界。

## MCP:两个方向

- **接入外部 MCP 服务** — 把第三方 MCP 服务器挂给 AI 使用,挂上后与内置工具一样受审批体系约束;
- **对外 MCP 端点** — 在设置里开启(默认关闭)后,Forsion 桌面本身变成一个 MCP 服务,供 Claude Code 等外部客户端调用它的能力;面板里可以直接复制接入命令。

## 并行子任务与多视角

- **子任务并行** — 一件事拆成几路同时跑,子任务继承当前会话的上下文,不用重新交代背景;
- **自我脑暴** — 同一个人格拆成多个视角互相批评,再汇总成一个结论;
- **分身模式** — 后台判断直接在完整上下文里顺手完成。

这几项的开关与适用场景见 [Agent 总览](../agents/overview.md)。

## 运行边界

- 单轮任务有**成本上限**,超出会被拦下并说明原因,不会无声地一直烧额度;
- 工具执行的关键节点可以挂自定义处理(Hooks),面向进阶用户;
- 自动化规则里的任务没有人守在旁边,审批会一直等不到人。给自动化用的 Agent 配**完全放行**档,或只开放无需审批的工具。
