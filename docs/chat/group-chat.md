# TEAM 与 Team Desk

[English](group-chat.en.md) · **简体中文**

Forsion v2.11 的 TEAM 把多个 Agent 组织成可以分工、讨论与持续使用的团队。成员在各自子会话里并行工作，主会话接收进度、问题、交接和公开产物；你可以在同一处了解进展并参与决策。

## 从两个成员开始

在输入框上方选中两个及以上 Agent，即可进入团队模式。可以先试用 Aria 与 Recita：一个探索表达方向，一个检查假设与依据；再按任务需要添加其他成员。角色是可调整的工作方式，最终判断仍由你作出。

需要长期复用时，在 **Agents Space** 建立团队、选择成员并填写职责。长期团队有独立的 `config.toml`、`TEAM.md` 和 `Library/`：

- **成员与职责**：写清每个人负责什么，例如“根据材料拟提纲”或“检查引用是否支持结论”。
- **TEAM.md**：记录全员共用的目标和协作约定，例如产出格式、交接方式、如何标出未核实信息。
- **Library**：保存团队资料；共同工作不代表成员自动共享所有私人记忆或无条件读取全部文件。

临时的项目团队模式不等于建立了一份持久团队配置。

## 看见分工，也看见过程

成员各自在子会话中调用工具、展开草稿，向主会话发送有用的进度、问题和最终结果。**Team Desk** 展示成员的工作状态，包括工作中、等待审批、已完成与失败；点开成员可以查看完整的子会话。

成员需要审批时，请求会提交到主聊天；公开产物也同步回主会话。你可以审阅、处理审批、打开文件，继续修改实际产物。

你可以随时补充材料或 `@成员` 交代新的工作。完成的成员会停止发言，直到收到新的请求；全员完成后团队收场。**v2.11 使用并行团队模型，不再沿用旧版群聊的轮流发言与投票收场。**

## 让工作留在对应项目

私聊中使用 `@项目` 派遣任务，Agent 会在该项目里新开会话执行。“轨道”侧栏将私聊、外部引擎、团队与项目放在同一列表中，常用项可置顶。

普通会话里的**委派子任务**适合一次性拆分独立工作；**长期 TEAM**适合保留成员、职责与共同约定，反复开展协作。两者传递任务所需背景，不应理解为默认复制全部历史与所有 Agent 的记忆。

## 试一次有实际产物的协作

1. 在项目笔记里写下目标，放入几份来源。
2. 让 Aria 依据材料提出表达方向，让 Recita 检查论证缺口，明确各自的交付物。
3. 在 Team Desk 检查工作进展与子会话；需要调整时插话或点名。
4. 审阅公开结果，选定方向后，把提纲、证据与待确认项保存回项目。

这是建议的练习，不是预录的运行结果。TEAM 使用本地模式，实际工作依赖配置的模型、资料与工具权限；每位 Agent 的人格、记忆和权限仍可以分别管理。
