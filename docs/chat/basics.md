# 对话基础

## 消息是怎么呈现的

- **流式输出** — 回复逐字出现,随时可点停止。
- **思考过程** — 推理型模型的思考默认折叠为一行(✦ 思考过程),点开可看全文。
- **工具调用** — AI 动手干活(读文件、跑命令等)时,每一步以工具卡片内联展示,连续的步骤自动折叠成组,点开看详情。见[工具与审批](tools-and-approvals.md)。
- **待办与计划** — 复杂任务中 AI 会展示自己的待办清单和计划卡片,进度一目了然。
- **右侧面板** — 窗口够宽时,聊天右侧显示本次任务的概览卡,agent 也可以把做出来的东西直接摆在那里。见 [Agent Desk 与任务概览](agent-desk.md)。

## 消息操作

悬浮在消息上可以:

| 操作 | 说明 |
|------|------|
| 复制 | 复制整条内容 |
| 重新生成 | 对最后一条回复不满意?再来一次 |
| 分支 | 从这条消息岔出一个新会话,原会话不受影响——适合"换个方向试试" |
| 编辑 | 修改你自己发过的消息并重跑 |
| 朗读 | 配置了语音(TTS)后出现,把回复读给你听 |

## 插话等待区

AI 干活的过程中你可以继续发消息:补充要求、纠正方向,不用等它跑完。任务跑动期间发出的消息**先停在输入框上方的等待区**,还没有进入对话:

- 每条都可以删掉,也可以按 **↑** 撤回到输入框里再改;
- 点**立即插话**会打断当前任务,消息马上送达;
- 不打断的话,消息会在任务跑到合适的节点时送入,并从等待区移进对话里。

被打断的那条回答会被标记出来,下一轮 agent 知道任务还没做完,会接着往下干,而不会当成已经收尾。

## 斜杠命令

在输入框的**任意位置**输入 `/` 都能唤出命令菜单,已经写好的内容保留。内置命令按用途分组,常用的几条:

- 看状态:`/help` `/status` `/cost` `/tools` `/agents` `/mcp` `/plugins`
- 管会话:`/export`(全量高保真导出)、`/copy`、`/retry`、`/compact`(压缩上下文,带进度条)
- 调配置:`/approval`(切换审批档)、`/memory`、`/config`、`/login`

**自定义命令**:在 `~/.tangu/commands/` 里放一个 md 文件,文件名就是命令名,正文就是发出去的提示词。正文里可以写 `$ARGUMENTS`(命令后跟的全部内容)或 `$1`…`$9`(逐个参数),调用时自动替换。

## 把东西拖进聊天

从工作区把**会话、笔记、文件**拖进输入框,松手即生成一条引用:

- 拖笔记或文件 — agent 读得到它的内容;
- 拖会话 — agent 读得到那个会话里聊过什么,适合"接着上次那件事往下办"。

## 会话之间

- 侧栏的会话**悬停即预览摘要**,不点开也知道那条聊的是什么。
- `[[` 双链补全可以引用会话,把一次对话挂进笔记网络。见[双链与属性](../amadeus/links-and-properties.md)。
- 新开的会话**延续你上次用的审批档、模型与思考档**,不必每次重设。审批四档的含义见[工具与审批](tools-and-approvals.md)。

## 出错与中断

- 请求因网络抖动失败时会**自动重试**(最多 3 次,间隔 1.5 / 3 / 4.5 秒),聊天区出现琥珀色提示,例如:

  > ⟳ 网络波动,3.0 秒后自动重试(第 2/3 次)

  重试成功后提示自动消失。
- 回复已经开始输出、中途断线时会**自动接着写**,单次任务最多续 3 次。
- 报错给出的是能照做的说明(额度用尽、单轮成本超限、输入过长等),而不是英文错误码。额度相关见[账号、额度与积分](../reference/account-and-quota.md),其余错误的含义见[常见问题](../reference/faq.md)。

## 快捷键

常用操作均有快捷键,可在 设置 → 选项 → 快捷键 中查看和自定义。
