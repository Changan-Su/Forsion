# 仪表盘

仪表盘是 Amadeus 里的一种笔记。它不按上下顺序排内容,而是把每一块内容装成一张**卡片**,按顺序流进一张网格。

你只决定两件事:**放什么**、**多大**。放在哪由排版算——所以随手拼出来的一页也是齐的。

适合做一览页:今天的日程、常看的表格、几个常用入口摆满一屏,打开就看完。

## 新建

三个入口,都叫「新建仪表盘」:

- 命令面板;
- 新建标签页里的功能卡;
- 笔记树的右键菜单(建在你右键的那个文件夹里)。

新建好的仪表盘是空的,会先给你几张**模板**(今日 / 工作台)——点一下就成型,再往上改。

## 卡片里能放什么

点「编辑布局」解锁后,顶栏的 ＋ 给出:

**分区标题** — 一条横贯整行的标题,把下面的卡片归成一组。它不是卡片,没有外壳。

**笔记里的内容** — 段落、标题、列表、图片,以及 `![[...]]` 嵌入的笔记、多维表、白板。卡片里用的是同一套块式编辑器。

**功能卡** — 时钟、天气(填城市)、网页(填地址)。

**数据卡** — 从一份多维表(`.db`)里取数:

- **数字卡** — 一个大数字。行数,或者某一列的求和 / 平均 / 最大最小。
- **图表卡** — 按某一列分组画图,横条 / 折线 / 环三选一。

**视图** — 菜单的「视图」一区列出所有可嵌入的视图:日历、待办、收件箱、活动日志、搜索、大纲、笔记、多维表、白板、PDF、图片……带「…」的要先挑一个文件。卡片里的视图和标签页里的是同一个,照样能点能用;卡片右上角可以把它在标签页里打开。

## 排版:顺序 + 大小

解锁后:

| 做什么 | 怎么做 |
|---|---|
| 换顺序 | 拖动卡片 |
| 改大小 | 拖右下角的把手,或从卡片的「…」里挑尺寸档(小 / 中 / 宽 / 高 / 大 / 整行) |
| 删卡片 | 卡片右上角的垃圾桶 |

大小是**按格走的**,不是无级拉伸——所以任意组合都能拼齐。宽度记的是「占十二分之几」,窗口变窄时列数自动降档,半宽永远还是半宽,永远不会横向滚动,**文字尺寸一个像素都不变**。

同一行里的卡片统一取该行最高那张的高度,行尾不会留半个洞。

## 页面筛选:一处改,全页跟随

顶部的筛选栏是数据卡的总开关:加一条「状态 是 进行中」,这一页上**每一张数据卡同时收窄**——数字变、图表也变。

筛选按**属性名**匹配。某张卡的数据源里没有这个属性,它就不受这条影响,而不是变成空的。

这一条是仪表盘和「一屏里摆了几个面板」的分界线。

## 锁定与浏览

顶栏在「编辑布局」和「完成」之间切:

| 状态 | 行为 |
|---|---|
| 编辑布局 | 拖动排序、改大小、增删卡片;卡内容不接事件(整卡是拖拽面) |
| 完成(锁定) | 就是一张成品页:卡片直接点、直接用,不会误拖 |

卡片的外壳(圆角、描边、内边距、标题条)两态完全一致——锁定只是把排版用的把手收起来。

## 自由摆位(高级)

如果你要的是「把卡片摆在任意坐标上」,从「更多 → 切换到自由摆位」进画布模式:平移缩放、框选多选、八向调整、点阵与吸附。它记的是另一把布局键,和自动排版互不干扰,随时可以切回来。

旧版(自由摆位)建的仪表盘打开后仍然是自由摆位的,顶部会给一条横幅问你要不要转成自动排版;转换后原布局键仍留在文件里,可以随时切回去。

## 它仍然是一份笔记

这是理解仪表盘边界的关键:它不是一种独立的文件格式,而是笔记库里的一份 Markdown 文件,只换了呈现方式。所以——

- 全局搜索搜得到里面的文字;
- `[[仪表盘名]]` 可以双链引用它,反链一并统计;
- [在线同步](cloud-and-sharing.md)、共享链接、置顶、回收站一视同仁;
- 用 Obsidian 或任意编辑器打开这个库,它就是一篇普通笔记,内容都在(布局记在 frontmatter 的一个外来键里,卡片是普通代码块)。

换句话说,用仪表盘不会把内容锁进专有格式。
