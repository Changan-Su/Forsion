# 浏览器版与移动端

Forsion 不把你锁在桌面前。桌面端、浏览器版、Android 版共用**同一套账号**,登录之后会话、Agent、云端笔记都是同一份,在哪台设备上接着用都行。

## Forsion Web(浏览器版)

- 打开网页登录即用,无需安装;
- 运行在**云端模式**:对话、Agent、云端 Amadeus 库全部可用;
- 界面默认放大 10%,阅读更舒适;
- 手机浏览器访问自动切换为单列布局。

## Forsion Mobile(Android)

安装 APK,登录后直接连云端。界面按手机重排,一屏一件事。

### 顶栏

顶栏上只有三样东西:

1. **左右侧栏开关**;
2. **标签页按钮**,上面带着当前标签数量。点开是标签列表,可以切换、关闭,也可以新建;
3. **⋯ 菜单**。点里面的头像展开完整账号菜单:剩余额度、重置卡、邀请好友、用户中心、退出登录。

### 侧栏是推开式的

左右面板滑入时,会把正文原样推向另一边,而不是盖在上面 —— 你始终看得见正在读的内容。轻点一下,或者朝反方向滑,面板就收回去。

### 左面板底部

左面板底部常驻 **Space 切换条**,再往下是账号卡和设置入口。切 Space、看账号、进设置都在这一处完成。

### 写笔记

笔记编辑时,底部常驻一条工具栏:插入(打开 `/` 菜单)、上传文件、撤销、重做、收起键盘。输入法弹出时它贴在键盘正上方,手指不用来回够。笔记的封面图通铺到屏幕两边,正文左右留白收得很窄,小屏上能多装一点字。

### 返回

移动端适配安卓的**预测性返回**手势 —— 往回拖的时候就能看见会退到哪里。返回键按层次逐级生效:先收起弹层,再收起面板,再是页内后退,最后才关闭当前标签。

命令面板、快速查找、成就在手机上同样可用。

### 让 Tangu 操作这台手机

Android 版可以让 Tangu 替你在手机上做一些事。默认关闭,在 设置 → 高级 → 实验功能 里打开「允许 Tangu 操作这台手机」,系统会弹一次确认框。

打开后,**在这台手机上发起的对话**里,Tangu 可以:

- 打开 App 和链接,用高德 / 百度 / 腾讯 / Google 地图发起导航;
- 设闹钟和倒计时,打开 Wi-Fi、蓝牙等系统设置页;
- 播放 / 暂停 / 切歌,调音量,开关手电筒,把文字复制到剪贴板;
- 起草短信、邮件、电话和日历事件。

几条边界:

- **发送、拨打、保存永远由你来按**:Tangu 只把草稿填好交给对应的 App。
- 打开地图和浏览器以外的 App 时,手机上会先弹一个确认框,写明要打开哪个 App。
- Tangu 看不到其他 App 里的画面,也不能在里面点按或输入;打开 App 之后的操作交给你。
- 只有在手机上发起的对话能操作这台手机,电脑上的对话、Muse 和自动化不能。
- 这些指令和草稿内容会经过 Forsion 云端,并保存在对话记录里。

## 平台能力对照

| 能力 | 桌面端 | Web / 移动端 |
|------|:---:|:---:|
| 对话 / Agent / 记忆 | ✅ | ✅ |
| 云端 Amadeus 库 | ✅ | ✅ |
| 本地笔记库 | ✅ | — |
| 内置终端 / Computer Use / 本地文件工具 | ✅ | — |
| 自动化 / 收件箱 / Muse 盯任务 | ✅ | 部分 |
| 让 Tangu 操作手机(打开 App、导航、闹钟、草稿) | — | 仅 Android |

一句话:**碰你电脑的能力只在你电脑上**,其余随处可用。Web 与移动端连的是云端,本地引擎那一层不在。

## 数据如何流转

Web 与移动端读写的是云端数据:云端笔记库、云端会话。桌面端的本地内容,除非你开启[在线同步](../amadeus/cloud-and-sharing.md),否则不会出现在其他设备上。

Agent 的记忆在一轮对话结束后立即上云,手机、网页与桌面看到的是同一份。会话标题的自动总结在网页 / 手机端也会运行,这一项需要管理员在后台开启。
