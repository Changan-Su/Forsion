# 仪表盘

仪表盘是 Amadeus 里的一种笔记。它不按上下顺序排内容,而是把每一块内容装成一张卡片,摆在一张 **24 列的网格**上——拖动改位置,拉边角改大小。

适合做一览页:今天的日程、常看的表格、几个常用入口摆满一屏,打开就看完。

## 新建

三个入口,都叫「新建仪表盘」:

- 命令面板;
- 新建标签页里的功能卡;
- 笔记树的右键菜单(建在你右键的那个文件夹里)。

建好的仪表盘和普通笔记并排在笔记树里,点开就是网格。

## 卡片里能放什么

解锁状态下,顶栏的「添加卡片」菜单给出三类:

**笔记里的内容** — 段落、标题、列表、图片,以及 `![[...]]` 嵌入的笔记、多维表、白板。卡片里用的是同一套块式编辑器,可以直接在上面写。

**功能卡** — 时钟、天气(填城市)、网页(填地址)。

**视图** — 菜单的「视图」一区列出应用里所有可用视图:日历、待办、收件箱、活动日志、搜索、关系图、内置浏览器、终端,以及插件注册的视图。卡片里的视图和标签页里的是同一个,照样能点能用。

视图本身的说明见[工作区与界面](../getting-started/workspace.md)。

## 锁定与浏览

顶栏的锁按钮在两种状态间切换:

| 状态 | 行为 |
|------|------|
| 解锁 | 拖动、缩放、增删卡片,卡片里的文字可改 |
| 锁定 | 浏览模式:布局与文字都动不了 |

锁定不等于静止——双链和链接照点,时钟照走,天气照刷,视图卡片照常交互。摆好一张常看的仪表盘就锁上,当首页用。

## 它仍然是一份笔记

这是理解仪表盘边界的关键:它不是一种独立的文件格式,而是笔记库里的一份 Markdown 文件,只换了呈现方式。所以——

- 全局搜索搜得到里面的文字;
- `[[仪表盘名]]` 可以双链引用它,反链一并统计;
- [在线同步](cloud-and-sharing.md)、共享链接、置顶、回收站一视同仁;
- 用 Obsidian 或任意编辑器打开这个库,它就是一篇普通笔记,内容都在。

换句话说,用仪表盘不会把内容锁进专有格式。
