# 编码工作室与发布

编码工作室把需求、对话、项目文件和实时预览放在同一个 Space 中。你可以从一句想法开始，也可以打开已有的本地工程继续开发。

## 从想法开始

起步页提供 AI 助手、数据仪表盘、个人网站、互动讲解、图片工作室、研究助手六个可编辑模板。模板用于帮你把要求说清楚，点击后仍然可以改写。

填写项目目标，按需补充受众与必须保留的要求，再选择需要的 Forsion 能力。创建项目会新建本地目录，将完整简报和开发约束保存到 `FORSION_BRIEF.md`，并把简短、可读的要求放进左侧对话草稿。草稿保留你的目标、受众与约束原文；**确认发送后才开始调用模型**。后续在「项目简报」中保存修改，也会更新这份文件。

- 想先讨论方案，打开「项目简报」选择「先做计划」；它使用 Forsion 原有的计划模式。
- 准备实现时选择「开始构建」，检查生成的对话草稿后发送，也可以直接在左侧对话里发送需求。
- 模型、思考档、Agent、外部引擎、附件、语音、技能与权限继续使用对话区原有控件。
- Coding 对话固定关联当前项目，发送前会校正旧会话的执行目录；要切换工程，使用工作台顶部的项目返回入口。未打开项目时先在起步页创建或导入。
- 用「打开本地文件夹」接入已有工程。导入只是打开目录，不会改写里面的文件；最近打开的项目也会显示在起步页。

## 按需展开工具

新工作区默认保留对话与主预览，把更多空间留给正在做的应用。底部工具栏集中放置简报、版本、验收、文件与终端入口；预览设置位于地址栏旁，问题入口位于状态区。

「项目简报」「验收」「预览设置」默认在右侧 Temp View 中打开，「版本」「问题」默认在底部打开。每个工具顶部都能切换到左侧、底部或右侧，并记住当前项目中该工具选过的位置。再次点击入口会聚焦已有工具；移动或关闭后重新打开，未保存的输入仍保留。工具获得焦点时按 Esc 可以关闭；离开项目时会清理临时视图，临时工具不会写入持久工作区布局。

命令面板也能直接打开这些工具。Agent 可通过已有 `run_ui_command` 通道调用 `coding-studio.open-tool`，提供当前 `projectRoot`、`tool`（`brief/history/checks/issues/setup`）及可选 `side`（`left/bottom/right`）；该命令只打开界面。

## 布局与动效

起步页分区依次进入，补充需求与目录选项平滑展开、收起。工作台的预览/代码/并排、设备宽度、元素修改表单以及原生 Temp View 开合都有连续过渡。移动工具面板或切换模式时，预览页面保持同一进程，页面内尚未提交的输入与交互状态得以保留；刷新页面、源码更新触发的实时刷新仍会重新加载内容。

窄分栏中，模板和工具栏会重新排列，底部问题面板在有足够空间时并排展示错误证据与修改要求。系统开启「减少动态效果」时，界面与原生面板直接切换到目标尺寸。

## 在预览中迭代

主区有「预览」「代码」「并排」三种模式。AI 生成文件时不会强制切走正在看的预览；模式切换也会保留同一个预览进程及页面内状态。

预览支持自适应、768 像素平板、390 像素手机宽度。窄工作区可能需要横向滚动以查看完整设备宽度。文件变化后自动刷新，包括 AI 的文件工具、终端命令以及外部编辑器写入。需要保留页面操作状态时，可以关闭「实时刷新」，看到有新改动后手动刷新。

「选择页面元素」允许在实际页面上点击目标，然后写下修改要求。选中的元素定位、可见文字与片段会**加入对话草稿**，便于表达“只调整这个按钮”；不会自动发送。按 Esc 退出选择。

目前一次引用一个元素；它帮助 AI 理解页面目标，不保证能直接定位到对应源码行。截图批注和直接修改页面文字尚未提供。

预览沿用 Electron 的网页宿体，支持文件选择、下载、全屏和鼠标锁定。每个静态项目拥有独立的本机预览源，项目间不会共用浏览器存储。

## 已有 Vite、Next.js 等工程

即时预览适合 HTML、多文件 JavaScript/TypeScript、JSX/TSX 与 importmap 项目；它按需转译源码，不会替你安装依赖或启动后端。

对于已有开发服务的工程：

1. 点击「打开项目终端」，在该项目目录按其 README 启动开发命令；
2. 打开「预览设置」，输入 `localhost`、`127.0.0.1` 或 `[::1]` 的 HTTP(S) 地址；
3. 应用后，在同一工作台中预览和选择元素。

需要时可以切回即时预览。开发服务由你在终端中启动和停止；工作室不会自动安装依赖或配置后端。自定义服务也不会自动获得即时预览中的 Forsion SDK 路由，使用 SDK 时需要按工程的运行环境接入。

开发服务和静态发布是不同运行方式；自定义服务不会被当成可直接发布的静态文件包。

## 修改代码而不丢草稿

代码编辑器会显示读取、保存、失败和冲突状态。保存使用文件版本校验，按文件串行执行；切换文件不会让上一份文件的异步结果覆盖当前编辑器。

当 AI 或外部编辑器同时修改文件时，本地草稿会保留，自动覆盖暂停。你可以复制草稿、明确加载磁盘版本，也可以取回保留的恢复副本。刷新应用后发现未保存草稿时，会先提示恢复，不会直接覆盖磁盘文件。只读宿主、二进制和过大文件都有明确提示。

## 发现问题与确认结果

「问题」面板收集预览里的警告、错误和加载失败。补充发生了什么、预期结果，再点击「带上证据修复」，会将诊断请求及错误来源加入对话草稿。

面板中的记录是当前工作台的预览证据，不是完整网络请求记录或跨会话的排错历史。修复后仍需重试原来的操作，确认问题是否消失。

「验收」提供主要流程、手机宽度、空/加载/失败状态、刷新后的数据行为、键盘与对比度五项检查。它们是**人工确认项**，预览打开不会自动标为通过；项目有新改动时会重置。也可以让 AI 在计划模式下检查，但只有实际执行过的检查才应视为证据。

## 保存和恢复源码版本

满意当前效果时，在「版本」里给源码保存一个名称，再继续尝试其他方向。恢复前会要求确认，并自动备份当前源码，因此可以从列表中恢复刚才的状态。

范围是常见文本源码与配置：不包含依赖、构建输出、密钥、媒体等二进制资源、数据库或云端数据。单份上限为 512 个源码文件、16 MB；超过上限会明确报错。恢复会处理源码的新增、修改和删除；恢复期间被外部修改的冲突文件会保留并报告。

源码版本与引擎自动检查点各有作用：对话里的自动检查点记录受支持的 host 写文件工具；终端和外部编辑器的修改应使用这里的手动源码版本保存。生成仍在运行或存在未处理草稿时，先处理这些状态再恢复。

## Forsion 能力与发布

当前网页 SDK 支持 Forsion 账号、AI 对话、云端 Agent 与图像生成。项目简报中的能力选择会向 AI 提供对应的实际接口要求，不会自动授权账号、配置模型或创建云资源。内置预览使用桌面登录态，运行时仍需要检查登录、权限和可用性。

应用中的云端 Agent 使用服务端管理的模型和工具，不会继承开发对话的本机终端权限。当前 SDK 没有通用数据库接口；本机浏览器数据也不等于云端数据库。

准备发布静态项目时，使用「发布」打开原有 Forsion Connect 发布流程，确认应用名称、入口、公开链接与发布条款。项目需要位于 Forsion 的 `Project` 目录内；从其他位置打开的工程，应先复制到该目录。应用内 AI 使用访客自己的账号与额度。

已发布的网站在「公开」Space 中管理，也可以申请上架[应用市场](../customization/market.md)。发布需要正常登录和网络，本地预览与源码版本不依赖云端发布成功。

工作室当前没有自动全栈云部署、云数据库与 secrets 配置、GitHub 导入/双向同步或 Android 构建入口。有后端的工程需要按自身部署说明单独发布。
