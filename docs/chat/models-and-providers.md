# 模型与接入方式

Forsion 不绑定任何一家模型。四种接入方式可以并存,配置入口都在 设置 → 模型。

## 方式一:Forsion 账号(最省事)

登录 Forsion 账号即可直接使用官方云端模型,无需申请和管理 API Key。默认的模型选择由官方持续调优(对话、后台任务、生图各有默认档),保持默认即可自动跟随推荐;想固定用某一款也可以手动指定。

这条路按账号额度计费,额度按周结算(日额度同时生效),用尽也不会把当前这轮对话中途掐断。详见[账号、额度与积分](../reference/account-and-quota.md)。

## 方式二:自带 API Key

填入对应服务商的 API Key 即可使用该家的全部可用模型。多个服务商可以同时配置,不同会话、不同 Agent 可以各用各的。

Anthropic、Gemini、DeepSeek、通义、智谱、Kimi、OpenRouter、Ollama 等都是按各自的协议直连的,模型自身的特性(上下文长度、是否支持思考、能不能看图)也照各家的实际能力对待。比如 DeepSeek V4 提供 1M 上下文并支持思考档位。

## 方式三:订阅登录

手里有 **ChatGPT(Codex)** 或 **xAI Grok** 的订阅,可以用订阅账号 OAuth 登录,用**订阅额度**(而非按量 API 计费)驱动 Forsion。登录在浏览器里完成,凭据存在你自己的电脑上。

> ⚠️ **注意**:订阅登录仅在本地模式下可用。

### 想用 Claude

Claude 有两条路:

1. **直连 Anthropic API key** —— 按方式二填入即可,全部 Claude 模型可用;
2. **跑本机的 Claude Code** —— 在「运行引擎」里把这台机器上装好的 Claude Code 挂进来,由它承担整轮对话,用的是它自己的登录状态。见[外部引擎](../agents/external-engines.md)。

## 方式四:自定义服务商

任何兼容 OpenAI 接口规范的服务都能接入:填入地址与 Key,即可把私有部署、中转服务、或本机跑的模型当作一个服务商使用。

## 思考档位

思考强度共七档,从「关闭」到「最大」。档位按模型的实际能力下发——各家协议写法不同,Forsion 会按你选的模型用对应协议发线;选中的档位这个模型不支持时,自动往下靠到它支持的最近一档,不会因此报错。

## 模型选择器

输入框上方的模型药丸点开是两级菜单:一页选模型,一页选思考档。新开的会话会延续你上次用的模型与思考档,不必每次重挑。

## 辅助模型

后台任务和特殊 Agent 用的模型统称**辅助模型**,和对话主模型分开配置,里面包含一个「图像识别」槽位:主模型不认图时,截图、看图这类工具产出的图片先交给它转成文字,再进上下文。

辅助 LLM、图像识别、生图三处都是下拉选择,「默认模型」不需要手填。

## 按 Agent 指定模型

每个 Agent 可以单独设定自己的模型——让写作助手用擅长长文的模型、让代码助手用擅长编程的模型,互不干扰。见 [Agent 总览](../agents/overview.md)。

## 视觉与多模态

发图识图优先看当前模型自身的视觉能力;不具备时由辅助模型里的图像识别兜底。见[附件与图片](attachments-and-vision.md)。

## 联网搜索

搜索可以用你自己的 key:设置 → 模型 → 联网搜索,支持博查、Tavily、智谱、DuckDuckGo,填完即时生效,不用重启。选智谱时还能指定搜索档位。

## 运行环境与中国大陆网络

环境检测、「让 Tangu 装」和镜像源开关都在[安装与更新](../getting-started/installation.md)里讲。注意镜像源只影响运行环境与依赖的下载,模型服务本身能不能连上,取决于你选的服务商。
