# PDF 批注

把 PDF 放进库里,Amadeus 就是你的文献阅读器。与"批注存在应用数据库里"的方案不同,Forsion 的批注**直接写进 PDF 文件本身**——用系统预览、Adobe、手机上任何阅读器打开,批注都在。

## 支持的批注

**选中文字后:**

- 高亮(多种颜色)
- 下划线 / 删除线 / 波浪线

**任意位置:**

- **手写** — 用鼠标、触控板或手写笔在页面上自由涂写;
- **文字批注** — 直接在页面上写字;
- **便签** — 钉一条可展开的评论;
- **形状** — 矩形、椭圆、箭头等标记;
- **书签** — 把重要页加入书签列表,快速跳回。

## 改与撤

- **橡皮**只擦手写笔画,而且是一笔一擦——旁边的高亮、形状不会被连坐;
- 选中一条批注可以移动它或删掉它;
- **撤销**退回上一步操作。

## 阅读体验

- 连续滚动阅读、缩放;
- 缩略图侧栏与批注列表,按页浏览所有标注,点击直达。

## 嵌进笔记里

PDF 也能以 `![[文件名]]` 的形式嵌进笔记就地翻阅。嵌入块在正文里是只读的,方向键与 `</>` 源码按钮的行为见[编辑器](editor.md)。

## 与 AI 配合

PDF 就在你的库里,AI 可以读:"总结这份论文的方法部分"、"把我在这份 PDF 里高亮过的句子整理成清单"。

AI 读长文档时会先定位再精读,答案里给出的出处是一条**可点的引用条**——点一下,这份 PDF 就在对话右侧的
Agent Desk 里翻到那一页,不必自己去库里找、去翻页。引用条上显示的是「文件名 p.12」,链接里带的则是这份 PDF
在库中的完整位置(形如 `[[资料/论文.pdf#page=12]]`)——库里有同名文件时也不会点开另一份。自己在笔记里写引用
也是同一套写法;只写文件名而库里正好有多份同名,链接会显示成未解析的灰字,补上目录即可。

引用条还会**把被引的那句话涂黄高亮**出来(链接里带 `&q=<原文片段>`)。这个高亮是**临时的**——只画在屏幕上,
一个字节都不写进 PDF;关掉再开就没了。写进文件本体的是你自己做的批注,两者互不相干。原文对不上(排版换行、
OCR 误差)时就只跳页、不高亮,不会报错。

**库外的 PDF 也点得开**(比如你直接把 `~/下载` 里的书扔给 AI 读):引用条照样跳到那一页,但它是**只读**的
——批注要写进 PDF 文件本体,而写盘只对库里的文件开放。想批注就先把这本书放进库里。

**不止 PDF**。AI 读过的代码/文本文件同样能精确引用到行:引用条显示「文件名:42」(链接形如
`[[src/main.py#L42]]`,范围写 `#L42-L48`),点开在 Agent Desk 里以代码视图打开,滚到那几行并整行涂黄
——高亮同样只画在屏幕上,不写盘。库外文件按绝对路径照样点得开。笔记则引用到**标题**:`[[笔记.md#某一节]]`
渲染成「笔记 › 某一节」,点开在主区打开这篇笔记并滚到那个标题(找不到同名标题就只打开、不乱跳)。
Excel/Word 这类版式文档暂时只到文件级——想精读引用,让 AI 直接读 PDF 版更实在。

> ⚠️ **注意**:批注写入的是文件本体。若 PDF 设置了禁止修改的权限,批注功能会受限。
