# 快速上手

装好了?十分钟把核心流程跑一遍。

## 1. 连上模型

打开 设置 → 模型。你有几种选择,任选其一:

- **登录 Forsion 账号** — 最省事,直接用官方云端模型,不用管 Key。额度按周计,用尽也不会把你手头这一轮对话掐断,见[账号、额度与积分](../reference/account-and-quota.md)。
- **自带 API Key** — 支持主流模型服务商(含 Anthropic 直连),填入 Key 即用。
- **订阅登录** — 手里有 ChatGPT(Codex)或 xAI Grok 订阅的话,可以 OAuth 登录,用订阅额度跑 Forsion。

> 想用 Claude?两条路:一是填 Anthropic 的 API key 直连;二是新会话里选「运行引擎」,让本机装好的 Claude Code 来跑这一轮,见[外部引擎](../agents/external-engines.md)。

细节见[模型与接入方式](../chat/models-and-providers.md)。

## 2. 第一次对话

在输入框里随便聊点什么。你会看到:

- 回复**流式**出现,长思考的模型会先折叠展示"思考过程";
- AI 需要动手时(跑命令、读写文件)弹不弹**审批卡**,取决于你选的**审批档位**——四档分别是 只读 / 替我批准 / 全自动 / 自定义,每档都配了图标和一句说明;
- 消息悬浮后有 复制 / 重新生成 / 分支 / 编辑 等操作;
- 输入 `/` 唤出斜杠命令(`/help` `/status` `/cost` `/export` 等),自己写的命令放进 `~/.tangu/commands/` 也会出现在这里。

> 💡 **提示**:让 AI 干复杂活之前,可以打开**计划模式**——它会先给出完整计划,你点头后才动手,也可以直接"批准并自动开始执行"。见[工具与审批](../chat/tools-and-approvals.md)。

窗口够宽时,聊天右侧会有一张任务概览卡:本次任务的计划、工作范围、参考来源与产出文件都在上面。AI 做出来的笔记、图片、网页、代码也摆在那一侧,可以直接改。见 [Agent Desk 与任务概览](../chat/agent-desk.md)。

## 3. 记第一篇笔记

切到 **Amadeus** 空间,新建一篇笔记:

- 直接写 Markdown,`#` + 空格变标题,`[[` 呼出双链(笔记、附件、多维表、会话都能补出来);
- 输入 `/` 打开斜杠菜单,可以插入多维表、白板、代码块等;
- 一切内容都是你工作区目录里的 `.md` 文件。

见 [Amadeus 总览](../amadeus/overview.md)。

## 4. 让 AI 主动干活

试试自动化:打开**自动化**空间建一条规则。一条规则 = **触发 × 动作链**——触发可以是每天某个时刻、某个事件,或你插在笔记里的一颗按钮;动作可以串起好几步,比如"跑一次 Agent 汇总今天的日程 → 发一条通知"。结果落到**收件箱**,也可以转发到你的微信 / Telegram / QQ。见[自动化](../spaces/automation.md)。

## 5. 逛一圈市场

主界面打开**应用市场**:技能、代理、插件、空间、主题、网站应用六类,全部一键安装。见[应用市场](../customization/market.md)。

## 6. 逛一圈工作区

最后花两分钟认认界面:左边 Ribbon 上半区切 Space、下半区放命令,标签页可以拖成分屏或拆成独立窗口,底部状态栏显示当前 Space、运行中的会话数、同步进度和笔记字数,右上角是通知。应用内还有内置浏览器和内置终端。见[工作区与界面](workspace.md)。
