# Space 总览

Space(空间)是 Forsion 组织功能的方式。每个 Space 是一份**配方**:规定这个空间打开哪些视图、侧栏里放什么、面对哪一份数据。切换 Space,整个工作区随之换一副面孔。

Space 图标排在 Ribbon 上区,点一下即切换。

## 内置空间

| 空间 | 干什么 |
|------|--------|
| **对话** | 与 Agent 聊天,一切的起点 |
| **Amadeus** | [笔记系统](../amadeus/overview.md):文档、多维表、白板、仪表盘、PDF |
| **日历** | [聚合一切带日期的东西](../amadeus/calendar.md) |
| **收件箱** | [Agent 主动发给你的消息](inbox.md) |
| **自动化** | [让 AI 按规则自己干活](automation.md) |
| **编码** | [写代码、当场预览](coding.md) |
| **公开** | 统一管理你已发布的网页应用与[笔记分享链接](../amadeus/cloud-and-sharing.md) |

## 启用、关闭与默认空间

用不到的空间可以在设置里关掉,界面更清爽;随时能重新打开,数据不受影响。

也可以指定**启动时进入哪个 Space**——冷启动直接进它的默认布局,而不是恢复上次退出时的样子。

## 插件与市场里的空间

插件可以自带 Space:装好即出现在 Ribbon 上区,不用重启。[应用市场](../customization/market.md)的"空间"分类也提供第三方空间,每个自带说明,不合适就卸载。

## 空间与界面

Space 里的内容以标签页打开,支持拖拽分屏、拖出独立窗口、置顶 Mini 卡片。界面各部分怎么用,见[工作区与界面](../getting-started/workspace.md)。
