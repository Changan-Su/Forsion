# 自动化

有些事不值得你每天想起来一次。自动化 Space 让你把"什么时候 + 依次干什么"写成一条规则,之后它自己跑,结果送到你面前。

## 一条规则 = 触发 × 动作链

规则编辑器里,上面是**触发**(什么时候跑),下面是**动作链**(跑起来之后依次做哪几件事)。动作是可增删、可排序的步骤卡,一条规则能串起多步。

你也可以直接在对话里把事情交代给 Muse,见 [Muse 主动助理](../agents/muse.md)。

### 触发:什么时候跑

- **定时** — 三种写法:每天(每天固定时刻)、某一刻(指定的时间点跑一次)、每隔多久(按间隔重复);
- **事件** — 从事件目录里挑一个,目录里也包含[插件](../customization/plugins.md)自己声明的事件;
- **手动(按钮)** — 不到点也不等事件,只等你点(见下一节);
- **[多维表](../amadeus/databases.md)内容变化** — 表里的内容发生变化就触发。

### 动作:跑起来干什么

- **发通知** — 提醒你一声,并投进[收件箱](inbox.md);
- **跑 Agent** — 指定哪个 [Agent](../agents/overview.md) 来干,要干什么用人话写;
- **调工具** — 不经过模型判断,直接执行一个工具;
- **写多维表** — 加一行,或者改一行。

## 笔记里的按钮

笔记里可以插一颗**按钮**块,给它配一条规则,点一下就跑。这类规则用的是「手动(按钮)」触发:它不会自己动,只在你点的时候执行。适合做"每周把这份表整理一遍""把这篇笔记的待办同步过去"这类你想自己掌握时机的事。

## 工具调用的安全边界

「调工具」这一步没有模型在中间把关,所以闸门收得很紧:

- 只有白名单内、并且自身声明为"自动化安全"的工具,才会出现在可选列表里;
- 只能在规则编辑器里配置 —— Agent 不能在对话里替你往规则里塞一个工具调用。

列表里挑不到的工具,就是没过这道闸,不能靠改配置绕开。需要更大权限的事,交给「跑 Agent」这一步,按下面的审批规则走。

## 定时提醒都在这里配

需要"到点提醒我一下",就建一条定时触发的规则,动作选发通知。提醒会落到收件箱,也能按你的设置转发到[通道](../chat/channels.md)上的微信 / Telegram / QQ。

## 无人值守:权限与成本

- 自动化任务跑的时候没人在旁边点「批准」。给规则使用的 Agent 配**全自动**审批档,或者只让它用不需要审批的工具(见[工具与审批](../chat/tools-and-approvals.md));否则任务会停在审批卡上直到超时。
- 规则守候期间**不消耗模型额度** —— 只有条件命中、真正开始干活时才唤醒 AI。放一打规则在后台,日常成本为零。
- 事件类规则自带**冷却时间**,避免"AI 的动作又触发了规则"这类自激循环。

## 执行过程全程可查

- 每条规则有自己的**触发记录**:什么时候跑过、结果如何;
- 每次执行都是一个完整会话,点开能看到 AI 当时的每一步 —— 不是黑盒;
- 产出通过通知与[收件箱](inbox.md)送达。

## 聊天里的自动化建议

聊到值得自动化的事情时,回复末尾会出现几枚可点的**芯片**。点一下等于你自己把那句话发出去,这一刻不会建任何规则 —— 要不要建、怎么建,都在接下来的对话里由你确认。

## Agent 日程

除了规则,每个 Agent 还可以有**日程**:一次性或周期性的计划事项。日程可以选择到点自动执行,也可以只做规划提醒;所有日程都会汇入[日历](../amadeus/calendar.md)只读展示。
