# 多维表

多维表是 Amadeus 的结构化数据容器:管任务、追进度、记账、做清单。每张表是库里一个独立文件,可以嵌入任意笔记,也可以单独打开。

## 创建与嵌入

- 笔记里输入 `/`,选择"数据库",当场插入一张新表;
- 已有的表用 `![[表名.db]]` 嵌到别处——**同一张表,处处同步**;
- 写 `[[` 时,补全候选里就有多维表,不用先记住它的路径。见[双链与属性](links-and-properties.md)。

嵌进正文的表是一个只读块,方向键与源码查看的行为见[编辑器](editor.md)。

## 列类型

| 类型 | 用途 |
|------|------|
| 文本 | 任意文字,支持 `[[双链]]` |
| 数字 | 数值,可参与统计 |
| 勾选 | 是 / 否 |
| 日期 | 日期值,可上[日历](calendar.md) |
| 单选 / 多选 | 从选项池中选,选项带颜色 |
| 链接 | URL |
| 关联 | 搜索并链接到库里的笔记,点击 chip 直达 |
| 附件 | 上传文件存进库里;图片给缩略图,也是画廊卡片的封面 |
| 公式 | 按其他列计算:`{单价}*{数量}`、`if({完成},"✓","…")`,支持四则、比较、`round`/`concat`/`days` 等函数 |
| 关联表 | 关联**另一张多维表**的一行,chip 显示对方行标题 |
| 引用 | 沿关联表列取出目标行的某一列(可选计数/求和/平均/拼接聚合) |

## 多视图

同一张表可以建多个**视图**,各自记住自己的筛选、排序与列配置:"全部任务"、"只看未完成"、"按截止日排序"来回切换,数据只有一份。每个视图可以选表格、看板、日历、画廊、图表五种呈现方式之一。

## 筛选、分组、排序、统计

- **筛选**:按任意列的条件过滤行,多条件可选**全部满足 / 任一满足**,条件存进视图;
- **分组**:表格视图可按单选列分组,组头带计数、可折叠,组内新增自动带上组值;
- **排序**:多列排序,逐层比较,视图菜单里点击列循环 升→降→移除;
- **行序**:表格视图里可以手动调整行的先后顺序(无排序/筛选/分组时);
- **统计**:列底部可显示汇总——计数、求和、平均等,记账表的合计一眼可见。

## 行详情

点开一行可以在弹层中查看和编辑整行字段,适合列多的表。

## 上日历

带日期列的表可以**加入日历**:在日历空间把这张表勾选为成员,行会按日期落在日历格子上,拖拽即改期。见[日历](calendar.md)。

## 接自动化

多维表和[自动化](../spaces/automation.md)是双向打通的:

- **表的内容变化可以当触发条件**——有行被加进来、某个单元格被改动(可附「新值等于某项」的条件),就触发一条规则;
- **自动化的动作可以动表**——往表里**加一行**,或者**改一行**的字段(值里可写 `{{row.列名}}` 引用触发行)。

这些都能直接在自动化空间的**可视化构建器**里配置。"表里某行被标成完成就发条通知"、"每天早上往值班表里加一行"都是一条规则的事。

## 摆到别处去

- **仪表盘**:一张卡片可以装一张多维表,和笔记正文、时钟、天气摆在同一张网格上,见[仪表盘](dashboard.md);
- **公开分享页**:笔记分享出去之后,里面嵌的多维表在访客那边照常渲染,见[在线同步与共享](cloud-and-sharing.md)。

## AI 也会用表

多维表对 AI 可见可写:"把这个待办表里逾期的行列出来"、"往读书表里加一行《三体》"都可以直接说。
