# 快速上手

从你正在做的一件事开始：一项研究、一篇文章，或一个想实现的项目。下面的步骤把它逐渐放进你的 Second Brain。先完成前三步，再按需启用协作与跟进。

## 1. 连上模型

安装并打开 Forsion Desktop，在**设置 → 模型**选择连接：

- **Forsion 账号**：登录后使用官方托管模型。
- **自己的 API**：添加模型服务商和 API Key，支持 Anthropic 直连与 OpenAI 兼容接口。
- **本地模型**：连接 Ollama 或自己的兼容模型接口。
- **订阅登录**：本地模式支持 ChatGPT（Codex）与 xAI Grok 的订阅登录。

本文的多 Agent 和 Muse 步骤使用**本地模式**。本地引擎可以调用你配置的云端模型；模型请求会发送给所选服务商。已安装的 Claude Code 或 Codex CLI 也可以作为外部引擎接入，详见[模型与接入方式](../chat/models-and-providers.md)和[外部引擎](../agents/external-engines.md)。

## 2. 给项目一个知识入口

在 **Note（Amadeus）** 用块编辑器建立一篇本地 Markdown 项目笔记，写上：

- **目标**：要做成什么、为谁做；
- **材料**：已有的文章、文件、参考链接；
- **待解决的问题**：还需要了解什么、下一步是什么。

用 `[[` 连接笔记、附件、多维表或会话，用 `/` 插入数据库、白板等内容。笔记保存在本地知识库，可以用普通文件工具检查和备份。

随后打开 **Agent（Tangu）**，引用这篇笔记，或告诉它具体文件路径，试着说：

> 读取这篇项目笔记，整理目前已知的事实、仍需验证的问题和下一步，把结果保存回知识库，并保留来源链接。

在请求的访问范围内授权它处理资料。Agent Desk 可以在对话旁展示笔记等产物；你可以直接打开、检查和修改。见[Amadeus](../amadeus/overview.md)、[Agent Desk](../chat/agent-desk.md)与[工具审批](../chat/tools-and-approvals.md)。

## 3. 建立跨会话的记忆

项目材料放在知识库，值得长期保留的工作偏好可以明确告诉 Agent：

> 记住：帮我做研究时，先列结论，再给来源；不确定的地方单独标出。

打开该 Agent 的**记忆面板**，确认它记下的内容。你可以修订记忆、查看历史，或将某条事实移出活跃记忆。开启新会话后，再围绕同一项目继续工作，检查它是否使用了合适的背景。

每个 Agent 的人格、Library、日志和记忆配置可以分别管理。本版本升级时会把尚未开启的 Historian 一次性打开；升级后手动关闭会被保留。Dream 的自动整理仍默认关闭。见[Agent 总览](../agents/overview.md)和[记忆系统](../agents/memory.md)。

## 4. 让 TEAM 分工推进

在输入框上方选择两个及以上 Agent 进入团队模式。先用 Aria 探索表达方向、Recita 检查依据，也可以添加自己的研究伙伴。

- **明确职责**：给成员不同的交付物，例如初稿、来源核查、待确认项。需要反复使用时，在 Agents Space 建立长期团队，为 TEAM 上传自定义头像，并用 `TEAM.md` 保存共同约定。
- **查看过程**：成员在各自子会话里并行工作，在 Team Desk 查看状态并点开详情；进度、公开产物与审批请求汇回主会话。
- **让成果有归处**：审阅后保存回项目笔记。私聊中的 `@项目` 也可以把任务派遣到对应项目的新会话。

普通会话也能委派独立子任务，按需传递背景。见 [TEAM 与 Team Desk](../chat/group-chat.md)和[Agent 总览](../agents/overview.md)。

## 5. 安排一次主动跟进

在**后台智能体**设置中检查 **Muse** 的活跃时段、心跳频率、预算和权限。本版本升级时会把尚未开启的 Muse 一次性打开；升级后手动关闭不会被重启重新打开。“审批”模式下，需要你决定的操作会进入待批队列；你也可以选择代批或全开模式。

把项目的后续事项交给 Muse 跟踪，例如让它在约定时间回顾项目笔记，整理未解决的问题。Muse 的日程、心跳和规则会触发后续工作，结果进入**收件箱**。

在收件箱里处理结果：交给 Muse 执行、开新会话继续，或忽略建议；遇到待批请求时批准或拒绝。Muse 还会积累自己的 Library 与工作日志，并可逐步构建自己的 Space。

若流程已经明确，用**自动化**创建“每天定时 → Agent 汇总项目进展 → 通知”的动作链；用**日历**汇总多维表里的日期和待办。见[Muse](../agents/muse.md)、[自动化](../spaces/automation.md)和[收件箱](../spaces/inbox.md)。

## 6. 给这条工作流补上能力

打开**应用市场**，按当前任务选择扩展：需要把视频收集成笔记，可以查看青鸟收藏夹；希望复用一套做事方法，可以安装 Skill；需要额外的工具或界面，可以安装插件。

一个插件捆绑包可以同时带来界面、引擎工具、Agent、技能和 Space。安装后查看说明、依赖与设置，再把它用于项目。MCP 也能接入外部工具与数据。见[插件体系](../customization/plugins.md)、[市场](../customization/market.md)和[Skills](../agents/skills.md)。

## 继续把成果接回来

研究过程中可以使用白板、PDF 批注或多维表；需要网页原型时，打开 **Coding Studio**，填写项目简报并确认发送创建出的会话草稿，再在预览中检查和修改结果。最后把成果、链接与下一步补回项目笔记。

拖动标签页、分栏或使用独立窗口，把会话和资料放在顺手的位置；可按需开启微信、Telegram 或 QQ 通道，在其他入口继续联系 Agent。
