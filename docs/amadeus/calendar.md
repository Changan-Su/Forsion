# 日历

日历空间把散落各处的"带日期的东西"聚合成一个视图。它自己不存数据——数据仍在你的表、待办和订阅源里,日历只是它们的时间投影。

## 显式成员制

日历显示什么,由你**明确勾选**:

- **多维表**:任何带日期列的表都可以加入日历(「添加 Forsion database」),行按日期落格;
- **待办**:待办按以今天为中心的时间窗聚合展示;
- **Agent 日程**:[Muse 及其他 Agent](../agents/muse.md) 的计划任务以**只读**方式显示——一眼看到 AI 接下来要替你做什么;
- **外部日历**:订阅或导入进来的 ICS 日历,同样只读。

没勾的不显示。日历不会自作主张把整个库翻个底朝天。

## 订阅外部日历

点「订阅外部日历(.ics)」粘贴一个 ICS 地址即可,Google / Outlook / Apple 日历里给出的「密钥地址」都认;手上只有一份文件的话用「导入 .ics 文件」。

- 外部日历是**只读**的:能看、能配色、能隐藏,但改不了对方的事件;
- 循环事件、全天事件、时区都按标准解析,和源日历对得上;
- 订阅源的 ⋯ 菜单里有「立即刷新」「重命名」「取消订阅」;
- 用地址订阅的会自动拉取更新;导入的本地文件是一次性快照,内容不随源变。

## 图例与跨库汇总

日历下方的图例列出全部成员,每条都缀着**所属库名**——本地库和云端库同时开着时,一眼看得出这条事件来自哪边。

- 每个日历单独改颜色、单独勾选显不显示;
- 打 ★ 的是新建事件默认落进去的库;
- 另一侧库的日历以**只读叠加**的形式汇总进来:看得到、能配色、改不了。要改,切到那一侧去改。

## 在日历里操作

- 点击条目直达来源(表中的那一行);
- 成员表的条目可以直接在日历上调整日期;
- 只读条目(Agent 日程、外部订阅、另一侧库)在日历里改不动——去它自己的地方改。

## 典型用法

把"项目任务表"(含截止日期列)加入日历,再订阅公司的共享日程当背景,然后让 Muse 每天早上把当天到期的事项发到[收件箱](../spaces/inbox.md)——看板、提醒、执行闭环。日历本身也能当一张卡片摆进[仪表盘](dashboard.md),开机就看见今天。
