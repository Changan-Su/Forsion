# 仪表盘

仪表盘是 Amadeus 里的一种 Markdown 笔记。默认采用结构化布局：用户决定放什么、顺序和偏好大小，系统负责对齐、分行与响应式重排。它适合做今日页、项目总览、数据摘要和常用工作台。

## 新建

三个入口都叫「新建仪表盘」：

- 命令面板；
- 新建标签页里的功能卡；
- 笔记树右键菜单（建在当前文件夹）。

新文件默认使用结构化网格。已有 `dashboard2:` 自由画布文件仍按原样打开，不会自动改写；顶部会出现一条横幅，询问是否转成结构化布局（也可以选择保持自由摆位，横幅从此不再出现），或从更多菜单随时切换布局模式。

## 为什么卡片能自动拼整齐

结构化仪表盘使用 12 列参考网格，但不保存绝对坐标。每张卡只保存顺序、偏好宽度和偏好高度；窗口变窄时，列数在 12、6、4、2、1 之间降档，卡片按同一比例重排，文字不会跟着整页缩放。

每种卡片还声明自己的尺寸契约：

- 时钟、天气和数字卡只提供适合快速扫读的小/宽档；
- 图表、待办、日历、收件箱等摘要提供宽/大/整行档；
- 笔记编辑器、数据库、白板、PDF 等交互工作区只提供大/整行/工作区档，避免把完整工具栏压进小格；
- 分区标题固定整行，不画卡片外壳。

自动编排会在这些合法档位里选择组合：相邻、可兼容的卡片优先拼满一行；不足整行的摘要组会居中。它不会制造任意尺寸，也不会把短卡强行拉到同行最高卡的高度。

## 卡片里能放什么

解锁后，顶栏的添加菜单包含：

- 内容：普通文本和笔记块；
- 功能卡：分区标题、时钟、天气、网页；
- 数据卡：数字统计、条形/折线/环形图；
- 应用视图：日历、待办、收件箱、活动日志，以及其它允许嵌入的视图；
- 原生工作区：笔记编辑器、数据库、白板和 PDF。添加时先选择对应文件，放入后可以直接输入和操作。

待办、日历、收件箱和活动日志在仪表盘里使用专用紧凑面：数据源与关键动作和完整视图相同，但不重复整页工具栏和多层滚动。卡片标题右侧的打开按钮可以随时进入完整标签页。

## 页面筛选

数据卡共享页面级筛选。在页面顶部加一条属性筛选后，所有认识该属性的数字卡和图表会同时更新；不包含该属性的数据源保持不变。筛选条件与布局一起保存在 frontmatter 中。

## 浏览与编辑布局

| 状态 | 行为 |
|------|------|
| 浏览 | 卡片内容直接可点、可勾选、可打开；没有拖拽遮罩 |
| 编辑布局 | 按住卡片任意位置拖动排序（与自由摆位一致）；双击卡片进入内容，可编辑正文、操作输入框和嵌入编辑器；右下把手和大小菜单只在该卡支持的离散档位间切换；可以增删卡片 |

编辑布局下整张卡都是拖拽面，双击才进入卡片内容（点卡片外任意处退出）。拖动排序时，其它卡片会实时让位重排，虚线轮廓标出松手后的落点；跟手的是一枚轻量卡片壳，原卡留在落点处降透明度作预告。松手即落位，不再二次跳动；按 Esc 可取消，布局滑回原样。

浏览与编辑布局使用同一套卡片外壳，切换状态不会改变圆角、表面或阴影。模式切换、卡片增删、自动重排、吸附改尺寸与菜单开合都有短过渡，并遵循系统的「减少动态效果」设置。

## 自由摆位（高级）

需要任意坐标、缩放和平移时，可从更多菜单切换到自由摆位：画布支持平移缩放、框选多选、八向调整大小、点阵背景与吸附对齐。自由画布使用 `dashboard2:`；结构化布局使用 `dashboard3:`。两套键可以共存，因此切换模式不会删除另一套布局，可随时回退。

## 它仍然是一份笔记

仪表盘不是独立文件格式：正文仍是 Markdown，布局和筛选只是额外 frontmatter。因此它可以被全局搜索、双链引用、同步、共享、置顶和放进回收站；用其它 Markdown 编辑器打开时，内容仍可读。
