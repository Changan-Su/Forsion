# Agent Desk 与任务概览

聊天区右侧有两样东西:**Agent Desk 演出面板**负责摆结果,**任务概览卡片**负责讲清楚这一趟在干什么。两者都跟着当前会话走。

## Agent Desk 演出面板

Agent 干完活可以把成果直接摆在聊天右侧,而不是只丢给你一句"已写入 xxx.md"。能摆的东西包括:

- **笔记** — 用的是真正的笔记编辑器,你可以在面板里直接改,改动就是改到那篇笔记上。
- **图片** — 生成的、截的、下载来的都能展示。
- **网页** — 做好的页面直接在面板里打开看效果。
- **代码** — 写出来的文件当场摊开对照。
- **任意应用内视图** — 白板、多维表、插件视图这些也能被摆进来。

写文件的过程本身也看得见:agent 一边写,面板里一边跟着长出内容,是**实时直播**,不用等它收尾才知道写成了什么样。

Agent 还能自己截一张面板的图回看渲染效果 —— 排版不对、图没加载出来这类问题,它看得见,也会自己回去修。

## 呈现方式由你决定

演出面板默认开启,不需要的话可以在设置里关掉。

面板**怎么呈现由你切换**:占多大、什么时候展开、是否收起来,都是你说了算。Agent 只能往面板里放内容,不能替你切换呈现方式。

## 任务概览卡片

窗口够宽时,聊天右侧固定显示一张任务概览卡片,列出本次任务的:

| 分区 | 内容 |
|------|------|
| 计划 | Agent 打算怎么做,做到哪一步了 |
| 工作范围 | 这次允许它读写哪些目录 |
| 参考来源 | 它读过哪些文件 |
| 产出文件 | 它写出了哪些文件 |

- **来源与产物都能点开** —— 点一下就能看到那份文件本身。
- **分区可折叠** —— 只想盯计划的时候,把底下几块收起来。
- **最近用过的排最上面** —— 文件多的时候,刚碰过的那几个一眼就看得到。

一个会话可以给 agent 加**额外的工作文件夹**,让它同时读写多个目录;加进来的目录在概览卡里逐条列出,随手就能移除。

**任务概览卡片不可关闭。** 它是你了解 agent 正在做什么的固定入口 —— 尤其在审批档位放得比较宽的时候,这张卡是你确认"它到底动了哪些文件"的地方。

## 边界

- 演出面板与任务概览都是**会话级**的:切到别的会话,看到的是那个会话自己的内容。
- 窗口太窄时任务概览卡片没有位置显示,把窗口拉宽即可。
- 面板里改笔记等同于改原文件,没有额外的草稿层 —— 改错了按笔记本身的方式撤销。
