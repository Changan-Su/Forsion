# 账号、额度与积分

桌面、网页、移动端是同一套账号——同一批 Agent、同一批会话,换个设备接着聊。

## 账号菜单

点左下角头像展开完整菜单:

- **剩余额度** — 本周与今日各剩百分之多少,以及下次重置的日期;
- **升级会员**;
- **使用重置卡**;
- **邀请好友**;
- **用户中心**;
- **退出登录**。

手机上,同款菜单在左面板底部的账号卡里。

## 额度怎么算

额度按**周**结算,日额度同时存在。

额度用尽时**不中途掐断**:当前这一轮对话保证跑完,超出的那部分记账,在下个周期结转。所以你不会遇到 agent 干到一半停在那里、留下半份产物的情况——最坏的结果是下个周期开局少一点。

## 额度用尽怎么办

两条恢复途径。

**重置卡** — 在商店里用积分购买,也可能由管理员发放。用掉一张,今日与本周额度一并恢复。账号菜单的「使用重置卡」、用户中心积分区的「就地兑换重置卡」都是入口。

**积分自动抵扣** — 用户中心里的开关,默认关闭。打开之后,额度用尽会自动扣积分继续用,不需要你手动处理。

## 积分

积分通过签到、成就等途径获得。用户中心的积分区里能做四件事:

- 看**余额**;
- **充值**;
- **就地兑换重置卡**;
- 用**兑换码** — 除了积分与会员时长,兑换码也支持「物品」类型。

## 邀请

邀请卡在**个人资料**里,带着你的邀请链接和已邀请人数。邀请人和被邀请人各得什么由平台配置,以邀请卡上的说明为准。

## 收件箱里的奖励

官方通知可以附带奖励——重置卡、积分或会员时长。**打开通知点「领取」才入账**,而且通知可能有有效期。领取规则见[收件箱](../spaces/inbox.md)。

## 什么不消耗 Forsion 额度

Forsion 额度只在你用平台托管的模型时消耗。走你自己那份账的,与它无关:

- 你自己填的 API Key(包括直连 Anthropic 的 key);
- ChatGPT / Codex 的订阅登录;
- 本机跑的模型(Ollama 之类);
- 在[外部引擎](../agents/external-engines.md)里跑本机的 Claude Code。

这几条的用量结在对应服务商那边,不看本页说的额度、积分与重置卡。
