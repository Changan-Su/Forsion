# 常见问题

## 连接与报错

**聊天区出现"⟳ 网络波动,X 秒后自动重试"是什么?**
瞬时网络故障,引擎正在自动重试(最多 3 次)。通常几秒内自愈,无需操作。

**"无法连接模型服务(fetch failed)"?**
网络不通或所选服务商不可达。检查网络、代理,以及 设置 → 模型 里的服务商配置。

**"连接中途断开(terminated),回复未完成"?**
回复流到一半连接断了。为避免内容重复,这种情况不自动重试——点**重新生成**即可。

**"鉴权失败"?**
API Key 失效或账号登录过期。去 设置 → 模型 重新配置或登录。

**"请求被限流 / 模型服务端错误"?**
服务商侧的临时问题,稍候重试;频繁出现可换用其他模型。

## 额度与账号

**额度用尽了怎么办?**
当前这一轮对话保证跑完,超出的部分在下个周期结转,不会把你掐断在半路。想立刻继续有三条路:用一张**重置卡**(今日与本周额度一并恢复)、在用户中心打开**积分自动抵扣**、或升级会员。入口与细节见[账号、额度与积分](account-and-quota.md)。

**我有 Claude 订阅,怎么在 Forsion 里用?**
没有"用 Claude 订阅登录"这条路。两个可行做法:一是直连 Anthropic API key(在模型接入里配置);二是在**外部引擎**里跑你本机装好的 Claude Code,由它接管这一轮对话。ChatGPT / Codex 的订阅登录是支持的。见[外部引擎](../agents/external-engines.md)与[模型与接入方式](../chat/models-and-providers.md)。

## 功能不可用

**模型列表是空的?**
还没有配置任何接入方式。见[模型与接入方式](../chat/models-and-providers.md)。

**发图片提示不支持?**
当前主模型没有视觉能力。要么换一个带视觉的模型,要么配好「图像识别」辅助模型——它会先把图转成文字再送进上下文。见[附件与图片](../chat/attachments-and-vision.md)。

**微信 / 浏览器自动化 / 本地文件 / 内置终端用不了?**
这些都是本地能力,依赖桌面端的本地引擎。浏览器版与移动端跑的是云端模式,没有这些能力。见[浏览器版与移动端](web-and-mobile.md)。

**微信 / Telegram / QQ 通道不回消息?**
通道由桌面端引擎接管,桌面应用需要保持运行(最小化即可)。应用关着的时候消息收不到也回不了。见[通道](../chat/channels.md)。

## 自动化

**规则到点没跑?**
两个最常见原因:

1. **应用没在运行** — 本地自动化由桌面端引擎执行,应用需保持运行(最小化即可);
2. **卡在审批** — 无人值守的任务等不到你点批准。给该规则的 Agent 配全自动权限,或只开放免审工具。见[自动化](../spaces/automation.md)。

## 同步与数据

**"在线同步"和"远程同步"有什么区别?**
两件事,可以同时开:

- **在线同步**把内容同步到你的 Forsion 账号,桌面、浏览器版、手机看到的是同一份;
- **远程同步**把本地库同步到你自己的第三方存储(如 Dropbox),数据不经过 Forsion。

两者的设置位置、同步方向与「预演」用法见[在线同步与共享](../amadeus/cloud-and-sharing.md)。

**订阅进来的外部日历改不了?**
订阅的 ICS 地址与导入的 `.ics` 文件都是**只读**的:它们只在日历里叠加显示,不能编辑,也不会写回对方。要改就去原日历改。见[日历](../amadeus/calendar.md)。

**能用 Obsidian 打开同一个库吗?**
可以,笔记本身就是磁盘上的普通 Markdown 文件。两点注意:多维表、白板、仪表盘这类内容用扩展写法落在 Markdown 里,在 Obsidian 中看到的是源码形态,不要在那边改;同一篇笔记也别两边同时编辑。外部程序(Obsidian、命令行、Tangu)改动了你正打开的笔记时,Forsion 会实时跟进。

**笔记文件在哪?怎么备份?**
笔记与文件都在你选的工作区目录里,直接拷走即可;账号、配置、Agent 记忆这些应用数据在用户目录下的 `~/.forsion` 与 `~/.tangu`。完整清单与各目录装了什么见[数据与隐私](data-and-privacy.md)。开着远程同步的话,"仅备份(推)"方向本身也是一份异地备份。

**删错了笔记?**
Amadeus 库内有回收站,先去那里找。

## 其他

**怎么看当前版本、查更新?**
设置 → 关于,可查看版本、更新日志,并手动检查更新。见[安装与更新](../getting-started/installation.md)。

**问题不在列表里?**
直接问应用里的 AI(它了解 Forsion 的功能),或通过官网渠道反馈。
