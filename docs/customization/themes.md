# 外观与主题

外观设置在 设置 → 外观。默认使用 Genesis 经典配色，阴影默认「立体」，菜单与浮层统一采用淡阴影；可切换「扁平」隐藏装饰阴影，选择会保存并同步到其他窗口。扁平不改变焦点、选中反馈或菜单动效。设计语言、配色、明暗、毛玻璃和字体仍可独立调整。

二级菜单以短淡入和轻微展开呼出，跟随系统的「减少动态效果」偏好。

## 三个维度

主题体系分三个独立维度,自由组合:

- **设计语言** — 决定应用的**气质**:字体、密度、质感。内置 Genesis 与 Genesis Glass；首次安装还会附带 Soft。可从商店或主题文件夹添加更多语言。语言只负责结构，颜色由配色轴决定。
- **配色** — 决定应用的**颜色**。内置经典、珊瑚、柔青、薰衣草、晴蓝，另有**自定义**:强调色管按钮、选中态与链接,背景色管整体底色,两个自由度分开调,"米白纸面 + 黛青强调"这类个人配方直接拾色即可。旧「知蓝」偏好的存储 id 保持兼容，界面名称改为「晴蓝」。
- **明暗模式** — 浅色 / 深色 / 跟随系统。所有设计语言与配色都同时适配明暗两态。

## Genesis Glass · 琉璃

内置主题里的一套 macOS 原生玻璃质感:外壳(ribbon、侧栏、标签栏)溶进窗后的桌面壁纸,设置、商店这类二级界面的侧栏同样是玻璃;主视图的纸卡保持实色、正文永远不透背景,所以任意配色都读得清。

它强制跟随系统外观 —— 系统切明暗,它跟着切。

## 就地调参

在设置页选中一套主题,下方直接给出这套主题的可调项:玻璃浓度、浮层模糊、透色鲜艳度、描边等等。具体有哪些旋钮由主题自己声明,所以不同主题露出的选项不一样,调完立刻生效。

## 字体三档

界面 / 正文 / 等宽三档字体分别可以指定:界面字体管菜单、按钮这类外壳文字,正文字体管笔记与对话的阅读区,等宽字体管代码块与终端。**留空 = 跟随主题**,主题作者的排版意图不会被覆盖。

## 细节

- 滚动条静止时透明,滚动或悬停时才显形;
- 丝滑光标(打字时光标平滑滑动)默认关闭,喜欢的话可以在外观里打开;
- 「宽松正文」「舒缓过渡」两个开关默认打开:笔记和对话正文的行距、段距更松;切换视图慢一点。不喜欢哪一样,在外观里单独关掉,关掉后和原来完全一样。
- 「外围淡出」默认关着,想要可以在外观里打开:Ribbon、未选中的标签、左侧栏和对话右侧的卡片平时淡一些,指针移过去或键盘焦点进来就恢复。

## 主题包

主题不止内置这些,可以自己装:

- **商店安装** — [商店](market.md)的「主题」分类,一键安装,装完在 设置 → 外观 里选用;
- **手动安装** — 主题包是数据目录 `themes/` 下的一个文件夹,拿到喜欢的主题包放进去即可;
- **投稿** — 做了主题想给别人用,通过商店投稿上架。

## 主题作者:设置页里的缩略图

设置 → 外观 的每张主题卡都会画一个小缩略图,只表达**结构**(颜色永远取用户当前的配色)。`theme.json` 里可选:

- `preview.shape`:`paper` / `glass` / `soft` / `compact`。不写时按 `tags` 推断(含 `glass`、`compact`、`soft` 各取其形),再看 `panelGap > 0`(浮卡布局)推成 `soft`,都没有就是 `paper`;
- `preview.font`:`sans` / `serif` / `mono`,缩略图里的字形。不写时 `tags` 含 `serif` 画衬线,否则无衬线(`mono` 标签表示单色配色,不会推成等宽)。

## 主题作者:动效归宿主管

主题管样子(颜色之外的结构、字体、圆角、阴影、布局),**动效由 Forsion 统一管理**。磁盘主题与商店主题装进来时,宿主会先把 `theme.css` 过一遍:

- **动效 token 的声明会被删掉**:`--duration-*`、`--ease-*`、`--menu-enter-duration` / `--menu-exit-duration`、`--droplet-duration`、`--collapse-duration`、`--tip-*`、`--hovercard-*`、`--switch-edge-*` 等,写在哪个选择器上都一样;`@property` 注册这些名字的整块也删掉。`theme.json` 的 `settings` 里用这些名字做的可调项同样不生效。设置页会在这套主题下面提示「N 项动效已忽略」。
- **你自己定义的 `@keyframes` 会被加上前缀** `t-<主题 id>-`,`theme.css` 里 `animation` / `animation-name` 对它们的引用会一起改写,所以照常能用;只是不能再用同名关键帧盖掉宿主的入场。经自定义属性转手的引用(`--a: fade 1s; animation: var(--a)`)不会改写,请直接写在 `animation` 里。
- **你自己的 `@layer` 名也会加同样的前缀。**
- **系统「减少动态效果」永远优先**:宿主把这条规则放在最先声明的层里,主题写 `!important` 也压不过。

想让界面「动起来不一样」,请等「动效主题」开放后单独提交;别在主题包里改动效。

## 全局一致

主题作用于整个应用 —— 对话、Amadeus 笔记、各个 Space、弹窗,一套气质贯穿到底;网页版与移动端也用同一套外观设置。
