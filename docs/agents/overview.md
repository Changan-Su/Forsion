# Agent 总览

在 Forsion 里,Agent 是**长期伙伴**:它有自己的人格、独立的记忆、专属的资料库和工作日志。你可以为不同的事创建不同的 Agent——写作教练、代码搭档、生活管家——它们互不串味。

## 一个 Agent 由什么组成

每个 Agent 在磁盘上就是一个独立文件夹,内容完全透明:

| 组成 | 说明 |
|------|------|
| **配置** | 名字、头像、使用的模型、开放哪些工具、审批档位 |
| **人格(SOUL)** | 一份 Markdown:它是谁、什么口吻、什么原则。写得越具体,角色越立体 |
| **记忆(MEMORY)** | 相处中记下的你的偏好与事实,一个 Agent 一份,见[记忆系统](memory.md) |
| **资料库(Library)** | 你塞给它的参考资料,回答时可随时查阅 |
| **日志(LOG)** | 它替你干过什么,有账可查 |

## 创建与管理

- **界面创建**:在 Agent 管理面板新建,填名字、写人格、选模型即可;
- **装现成的**:「应用市场 → 代理」里是别人调好的 Agent,一键安装,人格与配置一步到位;
- **让 AI 代劳**:直接在对话里说"帮我建一个每天督促我锻炼的教练 Agent",AI 会调用管理工具替你建好;
- **随时调整**:模型、工具开关、人格文件都可事后修改,立即生效。

## 内置 Agent

- **默认助手** — 通用型,开箱即用;
- **[Muse](muse.md)** — 主动型助理,会盯任务、感知你的使用情境、主动找你。

## 每个 Agent 各用各的配置

模型、[工具黑白名单与审批档位](../chat/tools-and-approvals.md)都是按 Agent 独立设定的。让"文件整理员"只能动文件、"资讯官"只能联网,权责分明。

## 它是怎么干活的

- **子任务并行** — 一件复杂的事可以拆成几路子任务同时推进,子任务继承当前上下文,不用你重新交代背景;
- **自我脑暴** — 同一个人格拆成多个视角,各自出主意、互相批评,最后汇总成一个结论;方案选型、写作定调这种"一个角度不够用"的事适合让它这么想;
- **分身模式** — 后台那些顺手的判断,在当前这份完整上下文里就地做掉,不另起一轮对话:看得到全部前情,也更省时间;
- **收尾有交代** — 长任务结束时会说清产物落在哪个路径、叫什么字面名称;交付网页时它会自己看一眼渲染结果再定稿。

干活的过程与产出可以摊在聊天右侧看,见 [Agent Desk 与任务概览](../chat/agent-desk.md)。
