# 外观与主题

外观设置在 设置 → 外观。默认使用 Genesis 经典配色，阴影默认「立体」，菜单与浮层统一采用淡阴影；可切换「扁平」隐藏装饰阴影，选择会保存并同步到其他窗口。扁平不改变焦点、选中反馈或菜单动效。设计语言、配色、明暗、毛玻璃和字体仍可独立调整。

二级菜单以短淡入和轻微展开呼出，跟随系统的「减少动态效果」偏好。

## 三个维度

主题体系分三个独立维度,自由组合:

- **设计语言** — 决定应用的**气质**:字体、密度、质感。内置 Genesis 与 Genesis Glass；首次安装还会附带 Soft。可从市场或主题文件夹添加更多语言。语言只负责结构，颜色由配色轴决定。
- **配色** — 决定应用的**颜色**。内置经典、珊瑚、柔青、薰衣草、晴蓝，另有**自定义**:强调色管按钮、选中态与链接,背景色管整体底色,两个自由度分开调,"米白纸面 + 黛青强调"这类个人配方直接拾色即可。旧「知蓝」偏好的存储 id 保持兼容，界面名称改为「晴蓝」。
- **明暗模式** — 浅色 / 深色 / 跟随系统。所有设计语言与配色都同时适配明暗两态。

## Genesis Glass · 琉璃

内置主题里的一套 macOS 原生玻璃质感:外壳(ribbon、侧栏、标签栏)溶进窗后的桌面壁纸,设置、应用市场这类二级界面的侧栏同样是玻璃;主视图的纸卡保持实色、正文永远不透背景,所以任意配色都读得清。

它强制跟随系统外观 —— 系统切明暗,它跟着切。

## 就地调参

在设置页选中一套主题,下方直接给出这套主题的可调项:玻璃浓度、浮层模糊、透色鲜艳度、描边等等。具体有哪些旋钮由主题自己声明,所以不同主题露出的选项不一样,调完立刻生效。

## 字体三档

界面 / 正文 / 等宽三档字体分别可以指定:界面字体管菜单、按钮这类外壳文字,正文字体管笔记与对话的阅读区,等宽字体管代码块与终端。**留空 = 跟随主题**,主题作者的排版意图不会被覆盖。

## 细节

- 滚动条静止时透明,滚动或悬停时才显形;
- 丝滑光标(打字时光标平滑滑动)默认关闭,喜欢的话可以在外观里打开。

## 主题包

主题不止内置这些,可以自己装:

- **市场安装** — [应用市场](market.md)的「主题」分类,一键安装,装完在 设置 → 外观 里选用;
- **手动安装** — 主题包是数据目录 `themes/` 下的一个文件夹,拿到喜欢的主题包放进去即可;
- **投稿** — 做了主题想给别人用,通过市场投稿上架。

## 主题作者:设置页里的缩略图

设置 → 外观 的每张主题卡都会画一个小缩略图,只表达**结构**(颜色永远取用户当前的配色)。`theme.json` 里可选:

- `preview.shape`:`paper` / `glass` / `soft` / `compact`。不写时按 `tags` 推断(含 `glass`、`compact`、`soft` 各取其形),再看 `panelGap > 0`(浮卡布局)推成 `soft`,都没有就是 `paper`;
- `preview.font`:`sans` / `serif` / `mono`,缩略图里的字形。不写时 `tags` 含 `serif` 画衬线,否则无衬线(`mono` 标签表示单色配色,不会推成等宽)。

## 全局一致

主题作用于整个应用 —— 对话、Amadeus 笔记、各个 Space、弹窗,一套气质贯穿到底;网页版与移动端也用同一套外观设置。
