## 定位

**Forsion is All You Need**<br>
本地优先的第二大脑工作台。<br>
你的积累，你和 AI 一起接着用。

一句话：你的东西放在本地的一张台面上，你和 AI 在同一个界面里接着用它。

- 主角是台面。Agent 是在台面上干活的帮手，不是产品本身。
- 品类词整个用「第二大脑工作台」，不单说「AI 工作台」或「AI 第二大脑」。
- 人和 AI 的关系叫「相互补全」：不是覆盖，是相互补全。对称的是文件的格式，决定权在用户。
- 不把 Forsion 和 Claude Code、Codex 摆成同一类来比；它们可以经 ACP 接进 Forsion 干活。

## 主线

官网首页和 README 用同一个例子「筹办社区书展」串起来，顺序也一样：

1. **主页是你的台面**：小组件摆在两边，资料是电脑上的普通文件。
2. **问一句，回答能接着用**：Tangu 先读文件再回答；回答带一张能算的卡，存成小组件，摆进仪表盘。
3. **卜算子先开口**：紧急的发消息，不急的写信，有自己的 Space。
4. **人类补完计划**：`AGENT.md`、`HUMAN.md`、`SOUL.md`、`MEMORY.md` 左右对称。
5. **缺什么，去商店**：官方插件、在对话里找、自己加来源；Forsion Clip。
6. **在它上面造东西**：一个文件夹就是一个插件；Space、View、UI 组件三层；先在沙箱里试。

每段先说能拿它做什么，再说是哪个功能。

## 说法的边界

| 说法 | 依据 | 边界 |
| --- | --- | --- |
| 卜算子先开口 | [卜算子](../agents/muse.md) | 在电脑上的 Forsion 运行时工作；运行时段、预算和审批由用户设 |
| 回答是能算的卡，存成小组件 | [更新日志](../../desktop/CHANGELOG.md) 2.13.7、2.14.0 | 安卓 App 里不渲染这类卡，只显示一行说明 |
| `AGENT.md` 只给某一位 Agent | — | 计划中，写的时候要标出来 |
| 记忆能让它忘 | [记忆](../agents/memory.md) | 忘掉后保留修订历史，不说「彻底删除」；整理记忆不是每晚定时跑，不说「你睡着时」 |
| Claude Code、Codex 接进来 | [外部引擎](../agents/external-engines.md) | 只拿到工作目录和这一轮的消息，读不到 Forsion 的记忆 |
| 二十多个官方插件 | 商店 | 数字随商店变，引用前看一眼 |
| 插件先在沙箱里试 | [插件开发](../customization/plugin-development.md) | 一份单独的 Forsion：空库、没登录 |
