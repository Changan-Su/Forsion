# 在线同步与共享

Amadeus 默认纯本地。要把内容送出这台电脑,有两套彼此独立的机制:

- **在线同步** —— 和你 Forsion 账号下的云端库对接,桌面、网页、手机看到同一份内容;
- **远程同步** —— 把本地库和你自己的第三方网盘对接,用来备份或搬运。

两套可以同时开,也可以都不开;开不开都不影响本地文件。

## 在线同步

### 云端库

在本地库之外,你可以创建**云端库**:内容存在云上,桌面端、[浏览器版、移动端](../reference/web-and-mobile.md)随处打开编辑。侧栏胶囊一键在"工作区(本地)"与"云端"之间切换,两边的会话与文件**互不混淆**。

### 按条目上云

不想整库上云?把本地库里的**某个目录或某篇笔记**挂到云端:

- 双向同步:本地改动推上去,云端(或其他设备)的改动拉回来;
- **子页面逐个勾选**是否同步,已经同步的条目在列表里能直接看出「已同步」;
- 云端内容按**同步 Vault 分区**归置,网页版和手机上同样看得到这些分区;
- 重命名、移动都会正确跟随;离线照常编辑,联网后自动对账;
- 同一文件两边都改过时,保留双方内容并生成**冲突副本**,不悄悄丢字。

> ⚠️ **注意**:云端单文件上限 5MB。超限文件会被跳过,侧栏以红色行明确提示,不会静默丢失。

## 远程同步(第三方网盘)

设置里的**「同步」**分区管这件事:把本地笔记库和你自己的网盘(**Dropbox** 等)对接。

- **链接登录**:点一下跳浏览器授权,授权码自动回填;万一本机回环端口起不来,也可以手动粘贴授权码;
- **三种方式**:双向 / 仅备份(只推不拉) / 仅还原(只拉不推)。两种单向方式**绝不传播删除**——一边少了文件,不会连累另一边;
- **预演**:正式跑之前先看清这一次将推哪些、拉哪些、删哪些文件,确认无误再执行;
- 传输并发、忽略规则、单文件大小上限都可调;
- 同步进度在[状态栏](../getting-started/workspace.md)和同步面板里实时显示。

远程同步搬的是文件本身,不涉及 Forsion 账号,也不提供跨端实时协作——要"手机上马上看到桌面刚写的字",那是在线同步的活。

## 页面共享(协作)

把某一页(连同其子页面)共享给其他 Forsion 用户:

- 生成**邀请链接**,可设访问密码;
- 成员按角色协作(编辑 / 查看);
- 页面上能看到协作者的**在线状态**;
- 共享页数量配额随订阅档位不同,以应用内显示为准。

## 公开分享

一键生成**公开链接**,任何人无需账号即可只读查看——发布一篇笔记就这么简单。

- 笔记列表与页面顶栏有**发布状态指示**,一眼看出哪些已经公开;
- 子页面**继承父页的发布状态**;
- 公开分享页支持渲染**多维表**;
- 链接可随时撤销,分享范围严格限定在你选的页面。

桌面端还有一个「公开」Space,把已发布的[网页应用](../spaces/coding.md)和笔记分享链接统一放在一处管理。

## 附件与云空间

云端库中的附件计入你的账号云存储,可在账号页统一查看。
