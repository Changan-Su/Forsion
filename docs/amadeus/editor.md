# 编辑器

Amadeus 编辑器是块式的:标题、段落、列表、表格、白板、代码……都是块,但书写体验保持纯 Markdown 的顺滑。

## Markdown 快捷输入

行首输入 Markdown 记号 + 空格,立即变成对应块:

| 输入 | 得到 |
|------|------|
| `#` ~ `######` + 空格 | 各级标题 |
| `-` 或 `*` + 空格 | 无序列表 |
| `1.` + 空格 | 有序列表 |
| `- [ ]` + 空格 | 待办项 |
| `\|` + 空格 | 引用块 |
| `>` + 空格 | 折叠块(Obsidian 折叠 callout);接着敲 `[!note]` 这类类型令牌则变成对应的 callout |
| ` ``` ` | 代码块 |
| `---` | 分割线 |

## 换行与切块

- **Enter** — 新起一个块。
- **Shift+Enter** — 块内换行:在同一段 / 同一项里另起一行,不新建块。
- 标题只能是单行(与 Obsidian 一致):在标题里按 **Shift+Enter** 与 **Enter** 相同,从光标处切出一段正文。
- 块内的换行按 Obsidian 的语义落成单个换行,重开笔记时看到的排版和你写的时候一致。

## Tab 缩进

- 在正文、标题、引用／标注、列表或待办里按 **Tab** 缩进，按 **Shift+Tab** 退回；跨块选中时，可缩进的块会一起移动。
- 列表／待办项前面有同级条目时，Tab 会把它变成前一项的子项；首项没有可嵌套的前一项时，整份列表按视觉档位缩进。图片和嵌入内容跟随所在段落缩进。
- 表格里的 Tab／Shift+Tab 继续切换单元格；代码块里的 Tab 插入空格。分割线没有正文，不参与缩进。
- 缩进档位随笔记保存。标题、引用和整份列表在 Markdown 源码中用相邻的不可见 HTML 注释记录档位，其他 Markdown 阅读器仍能正常阅读正文。

## 表格

- 单元格里按 **Enter** 移到下一行同一列，在末行按 Enter 会先加一行；**Mod+Enter** 跳出表格，在表后新起一段。
- **Shift+Enter** 在格内换行，落盘为 `<br>`，重开照样是两行。
- 末格按 **Tab** 自动加一行并进入新行首格。
- 在单元格里（没有选中文字时）右键，或点表格的 ⠿，打开块菜单里的「表格」区：在上方／下方插入行、在左侧／右侧插入列、删除行、删除列、左对齐／居中／右对齐（作用于整列）。右键时操作对准点中的那一格；从 ⠿ 打开时只给「在下方插入行」「在右侧插入列」，追加到表尾。

## 斜杠菜单

输入 `/` 呼出插入菜单,菜单项都带统一的一套图标(插件提供的条目也一样)。可以插入:

- **多维表** — 新建一张表并嵌入当前位置,见[多维表](databases.md);
- **白板** — 嵌入画布,见[白板](whiteboard.md);
- **分栏** — 把内容排成左右多栏;
- 代码块、引用、标题等常规块。

行样式、标题级别、Emoji 也都能就地切换;选中一段文字会浮出行内工具栏,其中的「链接」按钮给选中的文字套上链接。

斜杠菜单顶部有 **基本 / AI / 插件** 三个分类胶囊。输入 `/` 默认显示基本命令；点击胶囊或按 **← / →** 切换分类，**↑ / ↓** 选择当前分类的命令，**Enter / Tab** 确认，**Esc** 关闭。AI 写作、页指令、Agent 任务和提示模板都以普通命令行显示在 AI 分类中；插件注册的命令统一出现在插件分类。

输入命令名称时会搜索全部分类，并切到最佳匹配所属的分类，例如 `/ai` 会进入 AI。搜索后仍可手动切分类，输入内容保持不变；未安装相关插件或当前分类没有匹配时会显示空态。输入法选词和其他输入框的按键保持原有行为，命令按当前环境的能力显示。

代码块带语法高亮,支持主流语言;右上角可复制、切换语言。代码块里括号和引号自动补全(设置 → 笔记里可关),Shift+Enter 换行;要跳出代码块按 ⌘/Ctrl + Enter,位于文末时按 ↓ 或在末尾按 → 也会在它后面新起一段。

### 行内格式与链接快捷键

- ⌘/Ctrl + E 行内代码(选中文字后按反引号也一样);对齐改用 ⌘/Ctrl + Shift + L / E / R。光标在行内代码末尾时按一次 → 跳出代码,接着打的字落在代码外面。
- ⌘/Ctrl + K 插入链接;光标或选区在已有链接上时,按它会预填原地址,可改地址或「移除链接」。
- 选区工具栏可以用键盘操作:Alt + F10 进入,← → 移动,Enter 执行,Esc 回到正文。
- ⌘/Ctrl + Shift + H 切换 `==高亮==`。
- 双链与库内链接:单击在当前页打开,⌘/Ctrl + 点击或鼠标中键在新标签页打开;光标停在链接上按 Alt + Enter 打开,Alt + Shift + Enter 在新标签页打开(可在快捷键设置里改键)。
- 块菜单(⠿)里可以「复制标题链接」「复制块链接」(只给已有 `^id` 的块)和「移动到…」另一篇笔记的末尾;键盘上 ⌘/Ctrl + ⌥/Alt + / 打开块菜单。

## 页指令与 Agent 任务

**页指令**记录维护这篇笔记时应遵循的要求，例如保留来源、使用指定术语、维持章节结构。通过斜杠菜单插入，在块内直接编辑；要求随笔记保存。只有页面顶层的指令块生效，放进引用、列表、分栏或画布卡片内会提示移到顶层。Agent 分页读取正文时仍能看到本页指令，正文 AI 和「问 Tangu」也会携带它们。当前用户要求优先，指令不会继承到其他笔记，也不会改变工具权限或自行启动任务。

输入 **`@` + Agent 名称**，从「交办 Agent」分组选择成员，会插入一张待交办任务卡。也可以用 `/ai` 的「Agent 任务」创建，再选择 Agent、填写内容。点击 **交办** 后，先保存笔记和会话关联，再启动一次独立任务；笔记保持打开，Agent 使用原有审批设置。任务卡显示处理中、等待回应等实时状态，**查看会话**可打开过程和结果。重开已关联任务只查看原会话，不自动重发。恢复历史时无法确认运行阶段的卡片显示「已关联会话」，不把它当成已完成。

同一桌面配置下，在两扇窗口同时交办同一个任务也只发送一次。已发送任务保留本地关联记录；即使恢复到交办前的笔记版本，再次点击也会关联原会话。要发起另一项工作，请插入新任务块。等待创建会话时删除原块会停止后续发送，不会把任务关联到相同的副本。

**提示模板**适合反复使用的提示词。点击「使用提示」会打开预填好的新对话，由你确认发送。打开笔记、复制块、导入 Markdown 均不会自动执行；只读页只展示这些块。任务运行需要桌面端连接能访问当前智库的本地引擎。

这三类块仍保存在 Markdown 中：`forsion-instructions` 围栏包含指导文本，`forsion-task` / `forsion-prompt` 围栏保存带版本和块标识的 JSON。悬停点 `</>` 可查看原文；无法识别的版本或损坏的 JSON 保持为代码块，不会自动修写。

## 折叠小节

- 标题左侧有折叠按钮,点一下把这一节下面的内容收起来;有子项的列表项同样可以把子项收起来。
- 键盘:光标放在标题或有子项的列表项里按 **⌘/Ctrl + ⌥/Alt + Enter** 折叠 / 展开;光标在正文里按,收起的是它所在的这一节。命令面板(焦点不在正文时按 ⌘/Ctrl + K;正文里 ⌘/Ctrl + K 是插入 / 编辑链接)里还有「全部折叠」「全部展开」,可以在 设置 →「外观」→「快捷键」里给它们绑键。
- 折叠状态记在这台设备上(按智库和笔记路径),关掉重开、切到源码再切回都还是折着的;它不写进 Markdown 文件,换一台设备或用别的编辑器打开是全部展开的。
- 光标进到标题行时会露出原始的 `#` 记号,标题字号照旧不变。

## 标注(callout)

`[!note]` 这类标注块是可折叠的:

- **单击标题行** — 折叠 / 展开,带展开收起动画;
- **双击标题行** — 露出这一块的字面源码,光标移走(失焦)自动收回;
- 标题里可以写 `##`、`- ` 这类块级内容。

## 查看源码

公式、图片 / PDF / 文件嵌入、插件块这类渲染之后看不到原文的块,鼠标悬停时右上角会出现一颗 `</>` 按钮。点开显示字面源码,方便核对或直接改;光标离开后自动复原成渲染结果。

## 嵌入与引用

`![[名字]]` 语法可以把其他内容嵌进笔记:

- `![[图片.png]]` — 内联图片,可以和文字混在同一行;粘贴图片会自动保存并插入;
- `![[笔记名]]` — 转写整篇笔记(只读);同名笔记按当前笔记所在位置就近找(同文件夹 → 这篇的子笔记 → 全库),`|` 后面的别名或宽度不影响解析;
- `![[笔记名#标题]]` — 只转写那一节(从这个标题到下一个同级或更高级标题),`![[#标题]]` 转写本篇的一节;`![[笔记名#^块]]` 转写从 Obsidian 带来的块锚标着的那一段;旧笔记的 `![[笔记名#块ID]]` 照旧可用;
- 被嵌的笔记不存在时,嵌入处显示「嵌入丢失」和一颗「创建」按钮,点它在当前笔记下新建这篇;
- `![[表名.db]]` — 嵌入一张多维表;
- `![[画布名.excalidraw]]` — 嵌入一块白板。

引用和嵌入块带一颗「打开」按钮,点它跳到被引用的内容,⌘/Ctrl+点击在新标签页打开。

拖入或粘贴附件时先落一个占位,上传完再替换成正式文件,慢网络下能看到进度。

删除一篇笔记时,如果有些附件只被这篇笔记引用,会先问你要不要一并删掉;这次的选择可以记住,以后按记住的来。

## 光标、方向键与分屏

- 上下键在块内逐**视觉行**移动,长段落折行之后也对;跨到上一块 / 下一块时落在同一水平列上。
- 图片、嵌入、多维表这类只读块可以用方向键直接穿过去,穿过时该块被选中并露出源码。
- 丝滑光标(Word 那种光标滑动手感)默认关闭,在设置 → 外观里打开。
- 支持分屏;在编辑与预览之间切换时光标位置保留,不会跳回开头。

## 页面图标与封面

每篇笔记可以设置**图标**(emoji / 内置图标)和**封面图**,列表和页首都会展示——让常用笔记一眼可辨。
