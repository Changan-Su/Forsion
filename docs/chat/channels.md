# 通道:微信 / Telegram / QQ

通道(Channel)把 Forsion 接到你日常在用的即时通讯软件上。接通之后,你在微信、Telegram 或 QQ 里发一句话,就等于在 Forsion 里和 Agent 对话——不用打开电脑上的窗口,人在外面也能派活、看进度。

支持三种通道:**微信**、**Telegram**、**QQ**。

## 配置

在 设置 → 通道 里,每种通道各占一张卡片,分别配置:

| 配置项 | 说明 |
|------|------|
| 启用 | 这个通道的总开关,关掉即断开 |
| 凭据 | 该通道自己的连接凭据,填在卡片里 |
| 默认 Agent | 从这个通道进来的消息交给哪个 [Agent](../agents/overview.md) |
| 默认模型 | 这个通道**新会话**用哪个模型(已有会话用 `/model` 换) |
| 审批档位 | 询问我批准 / 替我批准 / 完全放行,决定 Agent 在这个通道里能自己做多少事。通道**没有「自定义」档** |

三个通道彼此独立:可以只开一个,也可以给微信和 Telegram 配不同的 Agent 和不同的审批档位。

改审批档位后,已连接的会话**从下一条消息起**按新档跑(已经在跑的任务仍按原来的档跑完),不需要重新扫码或重连。

## 会话是怎么组织的

**每次连接通道,都会开一个全新的会话**,不和桌面上的某个默认会话混在一起——通道里聊的内容自成一摊,不会把你手头正在跑的会话搅乱。

历史会话不会丢:它们留在侧栏的**通道文件夹**里,和普通会话一样可以随时点开切回、往下接着聊、或者翻查之前的记录。在通道里也能用 `/sessions` 列出、`/resume <序号>` 切回。

## 在聊天里用命令

通道是纯文本:没有按钮,也没有斜杠菜单。命令直接打字发出去即可;发 `/help` 随时看完整列表。中文输入法打出的全角 `／` 也认,Telegram 群里带 `@机器人名` 的写法(`/model@MyBot`)也认。

| 命令 | 作用 |
|------|------|
| `/help` | 显示命令列表 |
| `/status` | 本会话概况:模型、思考档(以及在这个模型上实际按哪档跑)、审批档、循环上限、工作目录、用量、是否有任务在跑 / 在等你批准 |
| `/model` | 不带参数:列出可选模型(带编号,● 为当前)。10 分钟内**直接回一个数字**就能选中 |
| `/model <名称或序号>` | 切换本会话的模型,名字写个大概即可(`/model opus`);匹配到多个时会列出候选让你回数字选。末尾加 `--default`(或「默认」)同时设为本通道新会话的默认模型 |
| `/think [档位]`(`/effort`) | 不带参数:显示当前思考档和本模型支持的档。带参数:设为 off / minimal / low / medium / high / xhigh / max 之一;模型不支持的档会如实告诉你按哪档跑 |
| `/approval`(`/permissions`) | **只显示**当前审批档,不能在通道里改(见下) |
| `/loop [1-200]` | 查看或设置本会话的最大循环轮数;`/loop default` 恢复默认 |
| `/compact [关注点]` | 压缩上下文:把之前的对话总结成摘要再续接。有任务在跑时会拒绝 |
| `/cost` | 本会话的 token 用量与费用 |
| `/stop` | 停止任务(与直接回「停止」相同) |
| `/new [标题]` | 新建会话并切换连接 |
| `/sessions`(`/list`) | 列出本通道的会话(● 为正在连接) |
| `/resume <序号>`(`/switch`) | 切换正在连接的会话 |
| `/agents` / `/agent <slug>` | 列出 / 切换本会话的 Agent。Agent 设定了模型的,会话模型一起切过去 |
| `/voice` / `/text` | 回复附带语音文件 / 切回纯文字 |

旧的短写法照样能用:`/n` `/新建`、`/ls` `/列表`、`/sw` `/切换`、`/h` `/帮助` `/?`、`/语音` `/文字`、`/agentlist`。

不认识的 `/xxx` 会回「未知命令」,**不会**当成普通消息发给 Agent;如果你本来就想发一段以 `/` 开头的文字(比如一个路径),去掉开头的 `/` 再发。

除了命令,还有几个**裸关键词**:

- **停止**(或 stop / 取消 / 中止)— 停掉这个聊天发起的**全部**任务,包括正在跑的和排在后面的;
- **批准 / 拒绝**(或 yes / no、好 / 不行 等)— 只在有待批操作时生效,平时说「好」不会触发任何事。

回复语言按这个顺序定:`config.json` 里 `channels.<通道>.locale` 手选的 `zh` / `en` → 环境变量 `TANGU_LANG`(与终端界面同一个)→ 系统语言环境变量(`LANG` 等)→ 都没有时按平台:微信 / QQ 用中文、Telegram 用英文。

注意:从访达 / 程序坞启动的桌面端通常拿不到系统语言,这时实际走的是最后一档 —— 用中文的 Telegram 用户会收到英文回复、用英文的微信用户会收到中文回复。想固定语言,就在 `config.json` 的 `channels.<通道>.locale` 写 `zh` 或 `en`。

## 切模型 / 思考档的两种办法

1. **用命令**:`/model`、`/think`,即时生效到本会话(见上表)。
2. **直接跟 Agent 说**:「切到 opus」「这题想深一点」。Agent 会调用 `update_session_settings` 帮你改(见[工具与审批](tools-and-approvals.md)里「让 Agent 帮你切模型 / 思考档」一节):
   - 在「询问我批准」「替我批准」档下,通道里会收到一张审批卡,写着它想改成什么和理由,回「批准」或「拒绝」;
   - 在「完全放行」档下直接切,不用你点头。

两种办法口径一致:

- **只改这个会话**,不影响其它会话;新会话的默认模型只有加了 `--default` 才会改;
- **下一条消息起生效**:已经在跑或排队的任务仍用原来的模型跑完。思考档例外——正在跑的任务从它的下一步起就按新档;
- **审批档改不了**:命令和 Agent 都不能改。

## 通道里的审批与提问

**审批**:Agent 要做需要你点头的操作时,通道里会收到一张审批卡(内容是它要执行的命令或要改的文件)。回「批准」执行,「拒绝」取消,「停止」结束整个任务。

- **10 分钟没人回复,自动按拒绝处理**:操作不会执行,通道里会收到一条说明,Agent 也会知道是「没人应答」而不是你拒绝了,然后继续把任务收尾;
- **同时有多张待处理的卡时逐张出现**(比如 Agent 并行派出的几个子任务各要一次批准,或 `/new` 之后新旧两个会话都在等你):回完一张再发来下一张,「批准 / 拒绝」和你的答复只作用于**眼前这一张**;每张的 10 分钟从它**显示出来**时算起;
- 待批期间你发了一条新的普通消息,旧审批视为放弃(拒绝),新消息排在后面跑;旧任务的收尾结果照样会发给你;
- 桌面端开着的话,也可以在桌面上点审批卡;在那边处理了,通道这边会自动接着把结果发给你。之后再在通道里回「批准」,会提示该请求已过期,不会被当成一条新消息发给 Agent。

**提问**:Agent 需要你拿主意时(比如给出几个方案让你选),通道里会收到问题和编号选项。回**序号**选对应项,或者直接打字回答;下一条普通消息就是你的答复。

**计划审阅**:会话开着计划模式时,Agent 会把计划发过来并列出三个选项——「批准,马上开始执行」「批准,等我下一条消息再开始」「拒绝,保持计划模式」。回序号选择;想改计划就直接打字写修改意见。

## 为什么通道里不能改审批档

通道消息**不带发送者身份**:绑到一个群聊时,群里任何人发的消息在 Forsion 看来都一样。如果能用 `/approval full-auto` 放宽权限,群里谁都能替你把 Agent 放开。所以审批档只能在桌面端的 设置 → 通道 里改,`/approval` 只负责告诉你当前是哪一档。

## 从收件箱转发到通道

[收件箱](../spaces/inbox.md)里的消息可以转发到通道。Agent 半夜跑完一个长任务、自动化规则触发了一条提醒——转发一下,消息就推到你手机上的微信 / Telegram / QQ 里,不必守着电脑等。

## 边界

有几件事要心里有数:

- **通道由桌面端在跑。** Forsion 桌面端开着,通道才通;桌面端关掉、电脑睡眠,通道就断了,这段时间发进来的消息不会被处理。要长期在线,得让那台电脑一直醒着。
- **凭据存在本机。** 各通道的凭据保存在你自己的电脑上,不上传。换一台电脑要重新配一遍。
- **通道停用或换凭据重启时,还没回复的审批一律按拒绝处理**(Agent 会知道是通道断了,不是你拒绝的),不会一直挂着;还没回答的提问留着,可以回桌面端答。
- **审批卡不一定有人看到。** 你在外面,审批卡可能 10 分钟内没人回,操作就会被自动拒绝。想让通道里的任务自己跑完,把档位放到「完全放行」;想稳妥,就保留「询问我批准」「替我批准」,只是要留意手机消息。见[工具与审批](tools-and-approvals.md)。
- **别把通道绑到多人群聊。** 群里每个人都能以你的身份让 Agent 干活、回「批准」。
- **单条消息有长度上限。** 微信一条约 2000 字,模型列表、计划正文这类长内容会截断,完整内容回桌面端看。
- **通道是聊天入口,不是完整界面。** 复杂的排版、笔记编辑、面板操作还是回桌面端做;通道适合发指令、追问、拿结论。
