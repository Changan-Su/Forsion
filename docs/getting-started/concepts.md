# 核心概念

## Tangu 引擎

所有 AI 能力的执行者。它负责与模型对话、调用工具(读写文件、跑命令、搜索……)、管理 Agent 与会话。桌面端内置了一个引擎实例,开箱即用;单个会话也可以改用**运行引擎**——把整轮对话交给你本机装好的外部 agent(比如 Claude Code)去跑,见[外部引擎](../agents/external-engines.md)。

## Agent(代理)

一个 Agent = 一个有身份的 AI 伙伴。每个 Agent 拥有:

- **人格设定(SOUL)** — 它是谁、说话什么风格、遵守什么原则;
- **独立记忆** — 与你相处中记下的偏好和事实;
- **资料库(Library)** — 你塞给它的参考资料;
- **自己的模型与工具配置** — 每个 Agent 可以用不同的模型、开放不同的工具。

系统自带默认助手和 [Muse 主动助理](../agents/muse.md),你也可以随意创建新的。详见 [Agent 总览](../agents/overview.md)。

## 会话(Session)

与某个 Agent 的一段对话记录。会话可以随时切换、并行多开,支持从任意一条消息**分支**出新会话。自动化规则、通道消息也会各自开出自己的会话,方便回看 AI 每次执行的完整过程。

## Space(空间)

Forsion 的功能以"空间"为单位组织:对话、Amadeus 笔记、日历、收件箱、自动化、编码空间、公开……每个空间是一个独立的功能界面,可以按需启用或关闭,市场里还能安装第三方空间,插件自带的空间装好即出现在 Ribbon 上。详见 [Space 总览](../spaces/overview.md)。

## 工作区(Workspace)

- **磁盘上的工作区目录**:你的笔记和文件的家,首次启动时选定,普通文件夹,永远归你。
- **窗口里的工作区布局**:标签页 + 可拖拽分屏,外加 Ribbon、侧栏和底部状态栏。会话、笔记、空间都以标签形式打开,可以左右分栏对照;还支持把内容**拆出独立窗口**,或开成置顶的 **Mini 卡片**小窗。详见[工作区与界面](workspace.md)。

## 你会撞到的几个词

- **审批档位** — AI 动手前问不问你,共四档:只读 / 替我批准 / 全自动 / 自定义。见[工具与审批](../chat/tools-and-approvals.md)。
- **思考档位** — 让模型多想一会儿的强度,从"关闭"到"最大"共七档,按你所选模型的实际能力下发,不支持的档位自动往下靠。见[模型与接入方式](../chat/models-and-providers.md)。
- **辅助模型** — 后台活儿专用的模型槽:总结、命名、图像识别、生图等等,和你聊天用的主模型分开配置。主模型看不了图时,图片先由图像识别槽转成文字再进上下文。见[模型与接入方式](../chat/models-and-providers.md)。
- **工作范围** — 本次会话允许 AI 读写的目录。默认是当前工作区,可以额外加别的文件夹,任务概览卡里逐条列出、随手移除。见 [Agent Desk 与任务概览](../chat/agent-desk.md)。
- **通道(Channel)** — 把某个 Agent 接到微信 / Telegram / QQ 上,在手机上直接跟它说话。每个通道各配启用、凭据、默认 Agent 与模型、审批档位。见[通道](../chat/channels.md)。
- **在线同步 vs 远程同步** — 前者是用 Forsion 账号把笔记、记忆、会话同步到官方云端,三端共享;后者是把本地笔记库同步到**你自己的网盘**(如 Dropbox),方式可选双向 / 仅备份 / 仅还原。两者互不冲突。见[在线同步与共享](../amadeus/cloud-and-sharing.md)。
- **额度与积分** — 用官方云端模型时消耗额度,按周计(日额度同时生效)。额度用尽时当前这一轮对话仍会跑完,超出部分结转到下个周期;积分可以在商店换重置卡立刻恢复本周额度。见[账号、额度与积分](../reference/account-and-quota.md)。
- **插件捆绑包** — 一个插件包里可以同时带引擎插件、Agent、技能和 Space,装一次全部就位,捆绑内容在父插件卡片里级联管理。见[插件](../customization/plugins.md)。

## 本地模式与云端模式

- **本地模式**(默认):引擎跑在你的电脑上,文件、命令、微信、浏览器自动化这类"碰你机器"的能力全部可用。
- **云端模式**:任务在云端执行(Forsion Web / 移动端即此模式),随处可用,但涉及本机的能力(本地文件、本地命令等)不可用。

## 数据目录

除工作区目录外,Forsion 在用户目录下维护一个 `~/.forsion` 数据目录:账号凭据(`auth.json`)、配置(`config.json`)、主题、插件在顶层;引擎自己的东西(Agent、记忆、技能、会话库、自定义斜杠命令)收在 `~/.forsion/tangu/` 子目录里。`~/.tangu` 指向这个子目录,命令行和第三方工具照旧能用这个路径。详见[数据与隐私](../reference/data-and-privacy.md)。
