# 安装与更新

## 下载

从 Forsion 官网下载页获取对应平台的安装包:

| 平台 | 安装包 | 说明 |
|------|--------|------|
| macOS | `.dmg` | 拖进"应用程序"即可 |
| Windows | 安装程序 | 按向导安装 |
| Linux | `.AppImage` | 赋予执行权限后直接运行,无需安装 |

## 首次启动

第一次打开 Forsion 会进入引导流程,引导页右上角可以切换 **中文 / English**:

1. **选择工作区目录** — 你的笔记与文件的存放位置(默认在用户目录下)。这是一个普通文件夹,随时可以用 Finder / 资源管理器直接查看。
2. **连接账号 / AI 服务** — 登录 Forsion 账号直接使用云端模型,或填入自己的 API Key。这一步不强制:点「暂时跳过」也能先进主界面,登录与接入随时可以在设置里补上,详见[模型与接入方式](../chat/models-and-providers.md)。
3. **挑个外观** — 后续随时可换,见[外观与主题](../customization/themes.md)。

## 自动更新

- **Windows / Linux**:应用内检测到新版本后自动下载,静默更新完成后自动重启,升级一步到位。
- **macOS**:应用内提示新版本,点「前往下载」获取安装包(受系统签名机制限制,不做静默替换)。

设置 → 关于 里可以手动「检查更新」,也能看到当前版本与更新日志。

### 测试版通道

设置 → 关于 里有「接收测试版更新」开关,**默认关闭**。打开后你会收到 `x.y.z-beta.N` 这类预发布版本 —— 功能更早拿到,也更可能踩坑;关着则完全看不到它们。

版本比较走标准 semver,正式版永远优先:测试版之后发布的正式版照常推送给你。所以用过测试版之后,一样能正常升回正式版轨道。

## macOS 的系统隔离属性

macOS 会给从网络下载的应用打上隔离标记。Forsion 首次成功打开后会自动清除包内残留的隔离属性,语音输入、内置引擎这类原生组件不需要你手动去终端敲命令。

## 环境依赖

一部分功能要求这台机器上有 Node、Python 之类的运行环境。设置里的环境检测会列出缺哪些,点 **「让 Tangu 装」** 就把安装任务交给 Tangu —— 它会挑这台机器上真有的包管理器来装。安装过程中要执行的命令仍然按你设定的审批规则走,见[工具与审批](../chat/tools-and-approvals.md)。

Forsion 自带**内置 Node 运行时**:即使系统里没装 Node,依赖 Node 的功能也能跑;系统装了 Node 就用系统的那份。

## 中国大陆网络优化

如果你在中国大陆网络环境下遇到下载依赖、安装组件缓慢的问题,可以在设置中开启**镜像源**,应用会自动改用国内镜像获取运行环境与依赖。

## 命令行工具

桌面端可以一键把 `tangu` 命令安装到终端,并随应用更新自动保持最新。详见[命令行(Tangu CLI)](../reference/cli.md)。
