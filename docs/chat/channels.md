# 通道:微信 / Telegram / QQ

通道(Channel)把 Forsion 接到你日常在用的即时通讯软件上。接通之后,你在微信、Telegram 或 QQ 里发一句话,就等于在 Forsion 里和 Agent 对话——不用打开电脑上的窗口,人在外面也能派活、看进度。

支持三种通道:**微信**、**Telegram**、**QQ**。

## 配置

在 设置 → 通道 里,每种通道各占一张卡片,分别配置:

| 配置项 | 说明 |
|------|------|
| 启用 | 这个通道的总开关,关掉即断开 |
| 凭据 | 该通道自己的连接凭据,填在卡片里 |
| 默认 Agent | 从这个通道进来的消息交给哪个 [Agent](../agents/overview.md) |
| 默认模型 | 这个通道的对话用哪个模型 |
| 审批档位 | 只读 / 替我批准 / 全自动 / 自定义,决定 Agent 在这个通道里能自己做多少事 |

三个通道彼此独立:可以只开一个,也可以给微信和 Telegram 配不同的 Agent 和不同的审批档位。

## 会话是怎么组织的

**每次连接通道,都会开一个全新的会话**,不和桌面上的某个默认会话混在一起——通道里聊的内容自成一摊,不会把你手头正在跑的会话搅乱。

历史会话不会丢:它们留在侧栏的**通道文件夹**里,和普通会话一样可以随时点开切回、往下接着聊、或者翻查之前的记录。

## 从收件箱转发到通道

[收件箱](../spaces/inbox.md)里的消息可以转发到通道。Agent 半夜跑完一个长任务、自动化规则触发了一条提醒——转发一下,消息就推到你手机上的微信 / Telegram / QQ 里,不必守着电脑等。

## 边界

有几件事要心里有数:

- **通道由桌面端在跑。** Forsion 桌面端开着,通道才通;桌面端关掉、电脑睡眠,通道就断了,这段时间发进来的消息不会被处理。要长期在线,得让那台电脑一直醒着。
- **凭据存在本机。** 各通道的凭据保存在你自己的电脑上,不上传。换一台电脑要重新配一遍。
- **通道里没人守着审批。** 你在外面,弹出来的审批卡不一定看得见。给通道配的审批档位如果是「替我批准」以外的严格档,任务可能停在半路等你点头。想让它自己跑完,就把档位放宽;想稳妥,就只让通道 Agent 用不需要审批的工具。见[工具与审批](tools-and-approvals.md)。
- **通道是聊天入口,不是完整界面。** 复杂的排版、笔记编辑、面板操作还是回桌面端做;通道适合发指令、追问、拿结论。
