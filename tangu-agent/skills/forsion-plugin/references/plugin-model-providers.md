# Native single-inference model sources

Feature-detect `ctx.registerModelProvider` in an engine plugin. Register `{id, listModels({signal}), resolveModel(modelId,{signal}), stream(input)}`. This local-engine-only API contributes selectable native models; it never starts a second agent loop. Tangu owns history, tool execution, approvals and usage recording.

The host assigns `plugin:<actual-engine-owner>/<provider-id>/<encodeURIComponent(local-model-id)>`. Provider IDs are kebab-case (1–64); local model IDs are 1–240 characters without controls and may contain `/`. Never assume a manifest alias equals a marketplace installation identity. Duplicate owner/provider registrations throw; another owner's namespace cannot be replaced. Omit `thinkingLevels` when unknown; the host then omits `thinkingLevel` and preserves source defaults.

`PluginModel` = `{id,name,contextWindow?,supportsVision?,thinkingLevels?}`. Vision defaults false; optional contextWindow is a positive integer. Thinking levels are a nonempty subset of `off/minimal/low/medium/high/xhigh/max`; the host clamps requests to declared support. `listModels` returns currently enabled metadata (max 512). `resolveModel` rechecks one local ID and returns matching metadata or null. Both receive a five-second timeout/revocation signal; failed listing hides that source without writing back empty state. Resolution failure never falls through to a different provider.

`stream(input)` receives one host-prepared request: `{modelId,messages,tools?,toolChoice?,temperature?,maxTokens?,thinkingLevel?,cacheKey?,signal,onResponseStart?,onToken?,onReasoning?,onToolCallDelta?}`. It gets no credentials or execution handle. Credentials remain inside your adapter. Forward the signal upstream. Messages use OpenAI-style roles/tool fields and may contain image parts. The tool delta callback takes `{id,name,argsLen,args,argsDelta}` (cumulative JSON argument text plus newly received fragment).

An optional frozen `input.context = {sessionId,userId,cwd}` identifies the current native run for local adapter isolation; cwd is nullable. It comes from the already loaded trusted run row and current native cwd, with no new DB query. Bind stateful external contexts by user AND session, never cwd alone. This identity is outside the inference payload: never forward it to an upstream model. No bound run means no context; never infer identity from cacheKey/request fields or guess home. Initial remote runs, remote HTTP inference and later remote steering are denied; midstream taint aborts upstream work. A queued native run uses its own origin rather than inheriting the previous request's origin.

Return `{content,reasoning,toolCalls,usage,finishReason?}` with final aggregate text and calls, even if callbacks were emitted. Tool calls are `{id,type:'function',function:{name,arguments}}`; arguments is JSON text. Do not execute calls. Usage requires actual nonnegative integer prompt_tokens/completion_tokens; optional cached_tokens/cache_write_tokens/reasoning_tokens use the same rule. Missing telemetry is an error, not zero. No FIM, image generation, or opaque provider-specific output-item support.

Registration is inside the host's outbound masking layer: the source receives filtered payloads and the host restores placeholders in text/tool arguments. Never add a parallel unfiltered inference path. Disable/unload/failed activation/replacement revokes the source, aborts pending operations, suppresses late callbacks and rejects old payloads. Dispose of upstream resources even when host cancellation has already stopped waiting.

Canonical types: `tangu-agent/plugin-api/tangu-agent.d.ts`. Bilingual author guides: Genesis `docs/customization/plugin-model-providers.md` and `.en.md`. Native context lookup for panels remains `sdk.runs.context` (see `tangu-host-apis.md`); it grants no execution or chat-history access.
