## 定位 / Positioning

**不止记下来，还能接着做下去。**

Forsion 是本地优先的 AI 第二大脑：在自己的 Markdown 文件上用块编辑整理知识，让可编辑的长期记忆保留背景，和有不同人格的 Agent 一起思考，用 TEAM 分工推进，再由 Muse 在授权范围内持续跟进。

**Remember it. Think it through. Keep it moving.**

Forsion is a local-first AI second brain: organize your own Markdown files with blocks, retain useful context in editable memory, think with Agents that bring different perspectives, divide work through TEAM, and let Muse follow up within the boundaries you set.

主线：**记录与连接 → 记住背景 → 团队思考与执行 → 主动跟进 → 成果沉淀**。插件扩展整条路径。每段介绍先解释用户能完成什么，再介绍实现它的功能。

Story: **Capture and connect → Remember context → Think and act as a team → Follow through → Keep the results.** Plugins extend the whole workflow. Lead each section with what the user can accomplish, then explain the features that support it.

## 五个宣传重点 / Five core messages

| 重点 / Focus | 可直接使用的短句 / Copy | 应展示的证据 / Evidence to show |
| --- | --- | --- |
| Markdown 块编辑 / Markdown blocks | **Markdown 的自由，块编辑的直观。** / **Markdown files. A block editor you can think in.** | 同一篇真实 `.md`：块编辑、斜杠菜单、分栏与源码；加入双链或资料嵌入。 / One real `.md` file: blocks, slash commands, columns, source, and linked or embedded material. |
| 可编辑记忆 / Editable memory | **重要背景，不必每次重新交代。** / **Keep the background worth carrying forward.** | 明确保存一条偏好 → 面板查看和修订 → 新会话检查使用情况。 / Explicitly save a preference, inspect and edit it, then check its use in a new conversation. |
| TEAM 设计 / TEAM | **让灵感有人展开，也有人认真挑错。** / **Room for imagination, scrutiny, and shared work.** | 人格差异、`TEAM.md` 和职责、Team Desk 并行进展、子会话与公开产物。 / Distinct perspectives, agreements and roles, parallel progress, child conversations, and public outputs. |
| 主动式 Agent / Proactive Agent | **交代之后，继续有人留意。** / **Keep the follow-up moving.** | Muse 的配置 → 收件箱任务卡 → 用户决定 → 执行记录和实际结果。 / Muse settings, an Inbox task card, the user's decision, execution record, and actual output. |
| 插件工作流 / Plugin workflows | **把你的工作方式接进来。** / **Bring your way of working.** | 一套插件实际完成收集、处理、落盘，展示其工具、技能或 Space。 / An installed plugin collecting, processing, and saving material through its tools, skills, or Space. |

支持层：多维表、白板、PDF 批注、仪表盘与日历负责组织材料；Agent Desk、Coding Studio 负责查看与制作成果；轨道、分栏、Mini Panel、语音与通道负责让工作容易继续。按场景展示这些能力。

Supporting layer: databases, whiteboards, PDF annotations, dashboards, and Calendar organize material; Agent Desk and Coding Studio expose and create outputs; Orbits, split panels, Mini Panel, voice, and channels help users keep working. Present these through the task they serve.

Forsion brings local Markdown block editing, editable long-term memory, AI teams, and a proactive assistant into one workspace. Divide work with TEAM, follow progress in Team Desk, save decisions to the project, and let Muse handle configured follow-ups. Extend tools, skills, and workspaces through plugins. Make each piece of thinking a starting point for the next.
