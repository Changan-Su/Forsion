# 应用市场

应用市场是 Forsion 生态的门面:别人打磨好的能力,你一键装上。

## 六类内容

| 分类 | 装到哪 |
|------|--------|
| **技能** | 给 AI 的[做事说明书](../agents/skills.md) |
| **代理** | 现成的 [Agent](../agents/overview.md):人格、配置一步到位 |
| **插件** | [桌面插件与引擎插件](plugins.md):界面能力与 AI 工具 |
| **空间** | 新的[功能空间](../spaces/overview.md) |
| **主题** | [外观主题包](themes.md),装完在 设置 → 外观 里选用 |
| **网站应用** | 别人发布的网页应用,点开即用,不用安装 |

## 安装与更新

- 详情页看介绍、截图与依赖,一键安装;
- 插件按真实类型自动装到正确位置 —— 桌面插件和引擎插件住在不同地方,你不用操心装错;
- 安装完不会把你拽去设置页;要配置的话,在插件详情页点「打开设置」;
- 「可更新」页集中列出已装内容的可用更新;
- 上架内容经过审核,你装到的始终是**过审版本**,上游仓库事后的改动不会悄悄进你的机器。

## 网站应用

「网站应用」这一类和其他五类不一样:它不往你机器上装东西,点开就在应用内的浏览器里跑。这些应用来自别人在[编码空间](../spaces/coding.md)里发布的作品,填一句简介申请上架、平台审核通过后出现在这里。

## 投稿

做了个好东西?市场内直接**投稿**:提交你的 GitHub 仓库,通过审核后上架,全体用户可见。

网页应用走另一条路——在你自己的发布管理里申请上架,见[编码空间与发布](../spaces/coding.md)。
