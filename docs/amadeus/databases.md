# 多维表

多维表是 Amadeus 的结构化数据容器:管任务、追进度、记账、做清单。每张表是库里一个独立文件,可以嵌入任意笔记,也可以单独打开。

## 创建与嵌入

- 笔记里输入 `/`,选择"数据库",当场插入一张新表;
- 已有的表用 `![[表名.db]]` 嵌到别处——**同一张表,处处同步**;
- 写 `[[` 时,补全候选里就有多维表,不用先记住它的路径。见[双链与属性](links-and-properties.md)。

嵌进正文的表是一个只读块,方向键与源码查看的行为见[编辑器](editor.md)。

## 列类型

| 类型 | 用途 |
|------|------|
| 文本 | 任意文字,支持 `[[双链]]` |
| 数字 | 数值,可参与统计 |
| 勾选 | 是 / 否 |
| 日期 | 日期值,可上[日历](calendar.md) |
| 单选 / 多选 | 从选项池中选,选项带颜色 |
| 链接 | URL |
| 关联 | 搜索并链接到库里的笔记,点击 chip 直达 |
| 附件 | 上传文件存进库里;图片给缩略图,也是画廊卡片的封面 |
| 公式 | 按其他列计算:`{单价}*{数量}`、`if({完成},"✓","…")`,支持四则、比较、`round`/`concat`/`days` 等函数 |
| 关联表 | 关联**另一张多维表**的一行(可设为多值);chip 上显示哪一列由「芯片显示列」定,缺省是对方首列;还可「限定候选」只让人从符合条件的行里挑 |
| 引用 | 沿关联表列取出目标行的某一列(可选计数/求和/平均/拼接聚合);反向引用可切成**可编辑投影**,见下 |
| 人员 | 人名(值就是显示名);候选来自库里已经填过的名字 |
| 自动编号 | 新行自动递增编号,可带前缀 |
| 创建时间 / 修改时间 | 建行、改行时自动盖章,不可手填 |

数字列还能设**小数位**与**单位前后缀**(如 `¥` / `元` / `%`)——只影响显示,存进文件的仍是纯数字;点进去编辑时看到的也是原始值。附件列可以放**多个**文件,再次上传是追加而不是替换。

### 双向关联:一处真值,两头可改

关联是**单向存值**的:真值只写在关联那一侧。反过来那一侧(引用列指回本表时)可以打开「作为可编辑关联」——它渲染成和关联列一样的 chip,也能点开挑行,但**自己不存值**,改动直接落到对方表的那一列上。于是两头看起来都能编辑,底下始终只有一份真值,不会出现两边对不上的账。

普通引用列与投影列的分工:投影列 = 关联本身(挑谁),普通引用列 = 沿着关联取值或聚合(拿对方的某一列)。

## 多视图

同一张表可以建多个**视图**,各自记住自己的筛选、排序与列配置:"全部任务"、"只看未完成"、"按截止日排序"来回切换,数据只有一份。每个视图可以选表格、看板、日历、画廊、图表、**表单**、**甘特**七种呈现方式之一。

- **表单视图**:纵向排列可填字段(计算列与自动盖章的列不出现),可设必填、默认值、字段说明与提交后行为(留在表单继续填 / 跳到表格)。提交一次 = 新增一行,适合让人按流程录入而不是直接在表格里改;
- **甘特视图**:按日期列把行画成时间轴上的横条,可按日/周缩放,有今日线;没填日期的行排在最后。目前是只读的,改期请到表格或日历。

**每视图独立列序/列宽**:视图菜单里打开这个开关,该视图就记住自己的一套列顺序与列宽;不打开则跟随全表(默认)。首列是标题列的铁律在视图里同样成立。

## 筛选、分组、排序、统计

- **筛选**:按任意列的条件过滤行,多条件可选**全部满足 / 任一满足**,条件存进视图;
- **分组**:表格视图可按单选列分组,组头带计数、可折叠,组内新增自动带上组值;也可按**日期列**分组,分「按日 / 按月」两档,没填日期的行归「未设置」并恒排最后;
- **层级树**:表格视图可以指定一个「指回本表」的关联列当父列,行按父子缩进显示、可折叠。父行被筛掉的子行当作根显示;遇到成环则整表退回平铺(不丢行);
- **排序**:多列排序,逐层比较,视图菜单里点击列循环 升→降→移除;
- **行序**:表格视图里可以手动调整行的先后顺序(无排序/筛选/分组时);
- **列序**:直接拖表头即可换列的位置,列菜单里也有「← 左移 / 右移 →」(触屏/键盘用)。列序对全表生效(不分视图),且**不受排序/筛选/分组影响**。⚠️ **首列是标题列**——看板/日历/画廊的卡片标题、以及别的表关联芯片上的文字都取自它,所以它位置固定,拖不走、也插不到它前面;
- **统计**:列底部可显示汇总——计数、求和、平均等,记账表的合计一眼可见;
- **导出 CSV**:按**当前视图**的可见列与筛选后的行导出,不是整表。

## 行详情

点开一行可以在弹层中查看和编辑整行字段,适合列多的表。

## 上日历

带日期列的表可以**加入日历**:在日历空间把这张表勾选为成员,行会按日期落在日历格子上,拖拽即改期。见[日历](calendar.md)。

## 接自动化

多维表和[自动化](../spaces/automation.md)是双向打通的:

- **表的内容变化可以当触发条件**——有行被加进来、某个单元格被改动(可附「新值等于某项」的条件),就触发一条规则;
- **自动化的动作可以动表**——往表里**加一行**,或者**改一行**的字段(值里可写 `{{row.列名}}` 引用触发行)。

这些都能直接在自动化空间的**可视化构建器**里配置。"表里某行被标成完成就发条通知"、"每天早上往值班表里加一行"都是一条规则的事。

## 摆到别处去

- **仪表盘**:一张卡片可以装一张多维表,和笔记正文、时钟、天气摆在同一张网格上,见[仪表盘](dashboard.md);
- **公开分享页**:笔记分享出去之后,里面嵌的多维表在访客那边照常渲染,见[在线同步与共享](cloud-and-sharing.md)。

## AI 也会用表

多维表对 AI 可见可写:"把这个待办表里逾期的行列出来"、"往读书表里加一行《三体》"都可以直接说。
