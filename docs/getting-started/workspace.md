# 工作区与界面

Forsion 的窗口分四块:最左是竖条 **Ribbon**,中间是标签页与主区,主区两侧各有一条可折叠的**侧栏**,窗口底部是**状态栏**。通知从右上角滑入。

## Ribbon(左侧竖条)

Ribbon 分上下两区:**上区是 Space**,点图标切换空间;**下区是命令**。

- 图标可以拖动改序,**拖到哪松手就落在哪**;
- 同区的图标可以收进**收纳夹**归拢,悬停展开再选;
- 放不下的自动收进「…」里,不会挤没;
- 任意命令都可以**钉进命令区**,当常用按钮使;
- 插件自带的 Space 装好即出现在上区。

## 标签页、分屏与独立窗口

会话、笔记、文件、功能视图统统以标签页打开:

- 把标签拖到主区边缘即**分屏**——左边笔记、右边对话,一边看资料一边让 AI 干活;
- 标签可以**拖出成独立窗口**,也可以开成置顶的 **Mini 卡片**;
- 独立窗口跟主窗口看的是同一份数据:Tangu、Obsidian 或命令行改了正打开的笔记,两边都实时跟进。

点「新建标签页」时,内容按来源分组:**最近使用** / Forsion 原生 / 每个插件各一组。「最近使用」覆盖所有文件与功能视图,不只是会话和笔记。卡片可以直接拖到主区或某条侧栏,**落点即开**。

## 侧栏

左右各一条侧栏,右栏默认折叠、需要时一键展开。侧栏里装的也是视图(工作区文件、大纲、记忆……),同样能重排、能拖进主区。工作区文件面板只常驻显示当前工作区,其余收在「显示全部工作区」下面。

## 状态栏

窗口底部一条状态栏,按当前视图与 Space 自动显示对应信息:

| 项 | 显示什么 |
|---|---|
| 当前 Space | 你正待在哪个空间 |
| 运行中会话 | 有几个会话在跑 |
| 同步 | 在线同步的状态与进度 |
| 笔记 | 当前笔记的反链数与字数 |
| 收件箱 | 未读条数 |

每一项都能隐藏、能拖拽排序,整条状态栏也可以关掉,开关在 设置 → 选项 → 状态栏。

## 通知

通知卡片从右上角滑入,多条自动堆叠补位;鼠标悬停时倒计时暂停;报错的那类常驻,要你手动关。

在 设置 → 选项 → 通知 里可以按事件、按插件分别开关,也能发一条测试通知看效果。

## 内置浏览器与内置终端

- **内置浏览器**:应用内直接开网页,站内链接不必跳去系统浏览器。不想要可以关掉,链接就回到系统浏览器打开。
- **内置终端**:真正的登录 shell——vim、top、ssh、彩色输出、Ctrl-C 都对,和你平时那个终端一样。

两者都是普通视图:能摆进标签页、能分屏,也能放进[仪表盘](../amadeus/dashboard.md)的卡片里。

## 命令面板、快速查找与缩放

- **命令面板**:所有命令的总入口,搜名字就能执行;
- **快速查找**:搜笔记与文件,选中即打开。

界面缩放也是命令——**放大页面 / 缩小页面 / 重置页面缩放**,桌面端还绑在 Ctrl/⌘ 的 `+` `-` `0` 上。

## 设置界面

设置里内容长的分区(常规 / 模型 / 智能体 / 插件 / 高级 / 技能 / 同步)在标题下多一排横向栏目,左右滑动切换,不用一路滚到底找。

## 加载与出错

切笔记、开会话、展开侧栏树时看到的是**骨架屏**,不是空白页;点开文件是先跳转再加载。某个面板加载失败只塌这一块并给出重试,整个应用不会变成错误页。
