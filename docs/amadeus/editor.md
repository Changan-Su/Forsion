# 编辑器

Amadeus 编辑器是块式的:标题、段落、列表、表格、白板、代码……都是块,但书写体验保持纯 Markdown 的顺滑。

## Markdown 快捷输入

行首输入 Markdown 记号 + 空格,立即变成对应块:

| 输入 | 得到 |
|------|------|
| `#` ~ `######` + 空格 | 各级标题 |
| `-` 或 `*` + 空格 | 无序列表 |
| `1.` + 空格 | 有序列表 |
| `- [ ]` + 空格 | 待办项 |
| `>` + 空格 | 引用块 |
| ` ``` ` | 代码块 |
| `---` | 分割线 |

## 换行与切块

- **Enter** — 新起一个块。
- **Shift+Enter** — 切块:从光标处把当前块切成两块,类型跟着走 —— 待办切出来还是待办,列表项切出来还是列表项。
- 块内的换行按 Obsidian 的语义落成单个换行,重开笔记时看到的排版和你写的时候一致。

## 斜杠菜单

输入 `/` 呼出插入菜单,菜单项都带统一的一套图标(插件提供的条目也一样)。可以插入:

- **多维表** — 新建一张表并嵌入当前位置,见[多维表](databases.md);
- **白板** — 嵌入画布,见[白板](whiteboard.md);
- **分栏** — 把内容排成左右多栏;
- 代码块、引用、标题等常规块。

行样式、标题级别、Emoji 也都能就地切换;选中一段文字会浮出行内工具栏,其中的「链接」按钮给选中的文字套上链接。

代码块带语法高亮,支持主流语言;右上角可复制、切换语言。

## 折叠小节

- 标题左侧有折叠按钮,点一下把这一节下面的内容收起来;折叠状态跟着笔记走,关掉重开还是折着的。
- 光标进到标题行时会露出原始的 `#` 记号,标题字号照旧不变。

## 标注(callout)

`[!note]` 这类标注块是可折叠的:

- **单击标题行** — 折叠 / 展开,带展开收起动画;
- **双击标题行** — 露出这一块的字面源码,光标移走(失焦)自动收回;
- 标题里可以写 `##`、`- ` 这类块级内容。

## 查看源码

公式、图片 / PDF / 文件嵌入、插件块这类渲染之后看不到原文的块,鼠标悬停时右上角会出现一颗 `</>` 按钮。点开显示字面源码,方便核对或直接改;光标离开后自动复原成渲染结果。

## 嵌入与引用

`![[名字]]` 语法可以把其他内容嵌进笔记:

- `![[图片.png]]` — 内联图片,可以和文字混在同一行;粘贴图片会自动保存并插入;
- `![[笔记名]]` — 转写整篇笔记,`![[笔记名#块]]` 只转写其中一块;
- `![[表名.db]]` — 嵌入一张多维表;
- `![[画布名.excalidraw]]` — 嵌入一块白板。

引用和嵌入块带一颗「打开」按钮,点它跳到被引用的内容,⌘/Ctrl+点击在新标签页打开。

拖入或粘贴附件时先落一个占位,上传完再替换成正式文件,慢网络下能看到进度。

删除一篇笔记时,如果有些附件只被这篇笔记引用,会先问你要不要一并删掉;这次的选择可以记住,以后按记住的来。

## 光标、方向键与分屏

- 上下键在块内逐**视觉行**移动,长段落折行之后也对;跨到上一块 / 下一块时落在同一水平列上。
- 图片、嵌入、多维表这类只读块可以用方向键直接穿过去,穿过时该块被选中并露出源码。
- 丝滑光标(Word 那种光标滑动手感)默认关闭,在设置 → 外观里打开。
- 支持分屏;在编辑与预览之间切换时光标位置保留,不会跳回开头。

## 页面图标与封面

每篇笔记可以设置**图标**(emoji / 内置图标)和**封面图**,列表和页首都会展示——让常用笔记一眼可辨。
