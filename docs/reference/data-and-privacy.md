# 数据与隐私

原则只有一条:**本地优先,云端可选**。不开的云功能,数据一个字节都不上传。

## 数据地图

你的所有数据在两个地方,都是普通文件:

| 位置 | 内容 |
|------|------|
| **工作区目录**(首次启动时选定) | 笔记、白板、PDF、多维表、AI 产出的文件 |
| **数据目录**(`~/.forsion`、`~/.tangu`) | 配置、账号凭据、Agent(人格 / 记忆 / 日志)、主题、插件、活动记录 |

这些目录拷走 = 完整备份;恢复时放回原位即可。

## 什么会离开你的电脑

只有这些、且只在你使用对应功能时:

- **调用模型** — 对话内容发给你选择的模型服务商(平台托管的,或你自己配置的),这是 AI 工作的前提;
- **登录 Forsion 账号** — 账号信息与订阅状态;
- **主动开启的云功能** — [在线同步与页面共享](../amadeus/cloud-and-sharing.md)、[记忆同步](../agents/memory.md)所涉及的内容;
- **应用市场** — 安装内容时的下载请求。

## 两种同步,流向不同

- **在线同步** — 笔记进 Forsion 云端,网页与手机上读的就是这一份。按 Vault 分区,子页面可以逐个勾选是否同步。
- **远程同步** — 直连你自己的第三方网盘(如 Dropbox),数据在你的电脑和你的网盘之间走,**不经过 Forsion 的服务器**。同步方向与「预演」怎么用,见[在线同步与共享](../amadeus/cloud-and-sharing.md)。

## 明确不上传的

- 本地笔记库(未开启在线同步时);
- [活动记录](../agents/muse.md)(只存本机,且默认不采集、需显式授权);
- API Key 与登录凭据(仅存本机;平台托管的调用由应用代理,密钥不落入网页环境);
- [通道](../chat/channels.md)凭据(微信 / Telegram / QQ)只存本机。

## 对外的口子

这几处会把内容或能力暴露到你的电脑之外,都要你显式打开:

- **对外 MCP 端点** — 默认关闭。开启后外部客户端能把 Forsion 桌面当 MCP 服务用,接入需要 token。
- **发布的网页应用与分享页** — 拿到的是**公开链接**,知道链接的人就能访问。[Coding Space 发布](../spaces/coding.md)与[页面共享](../amadeus/cloud-and-sharing.md)都是这个性质,发布管理里可以随时撤回、下架。
- **联网抓取** — `web_fetch` 只访问公网地址,重定向逐跳校验,不会被一条跳转带进你的内网。

## 透明度

- 笔记就是磁盘上的 Markdown 文件,用 Obsidian 之类的工具直接打开也行;
- Agent 的记忆是可以打开看、可以手改的文本;
- 配置是一份 JSON:`~/.tangu/config.json`;
- 每个 Agent 干过什么有日志;
- 每条自动化规则跑没跑有记录。

没有"它到底知道我什么"的黑盒。
