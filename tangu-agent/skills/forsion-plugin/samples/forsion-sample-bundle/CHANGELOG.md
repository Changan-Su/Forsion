# 更新日志

插件生态约定:每次发布在最上方追加一节(`## x.y.z — YYYY-MM-DD` + 变更条目)。宿主 `listPlugins`
会读本文件,渲染成插件详情页的「更新日志」段;**顶节版本要与 `manifest.json` 的 `version` 一致**
(不 bump = 用户装上后市场看不出换过版本,更新推不下去;有些插件的 `check.mjs` 直接断言这条)。
