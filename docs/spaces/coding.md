# 编码空间与发布

"帮我做个倒计时页面"、"把这份数据做成可交互图表" —— 编码空间为这类任务而生:AI 写代码,你**当场看到运行效果**,满意了直接发布出去。

## 工作方式

1. 在编码空间发起需求,AI 在工作区里创建项目文件;
2. 内置**实时预览**直接渲染页面 —— 改一版、看一版;
3. 文件就在你的工作区目录里,随时可以用别的编辑器接手,或部署到任何地方。

预览和[内置浏览器](../getting-started/workspace.md)用的是同一套宿体,所以鼠标锁定(3D / FPS 这类项目要用)、全屏、下载在预览里都能用,三维场景和加载外部资源的页面都跑得起来。

> 💡 **提示**:预览服务只对本地工作区目录内的文件生效,不会暴露目录之外的任何内容。

## 适合做什么

- 落地页、个人主页、活动页;
- 数据可视化、交互演示;
- 小工具(计算器、转换器、抽签器……);
- 快速原型:先让 AI 搭个能点的版本,再谈需求。

## 发布成网页应用

做好的东西可以**一键发布成网页应用**,拿到一条公开链接,任何人打开就能用。

- 发布本身不需要审核,链接发布完就可用;
- 访客用掉的 AI 用量记在**访客自己的账号**上,不花你的额度;
- 桌面端的「公开」Space 统一管理你已发布的网站与笔记分享链接。

## 上架应用市场

想让更多人看到,可以为已发布的应用**申请上架**:填一句简介提交,平台审核通过后,它会出现在「应用市场 → 网站应用」里,点开即用。

- 发布管理里随时看审核状态;
- 上架之后可以撤回、下架;
- 被驳回会给出原因,改完可以重新申请。

详见[应用市场](../customization/market.md)。

## 在页面里用云端 Agent

发布出去的网页应用可以直接用云端 agent:页面里写一行 `forsion.ai.agent`,就能发起一次云端 agent 对话。

- 它会联网搜索,也会跑 Python;
- 上下文由平台托管,你不用自己维护消息数组;
- 用哪个模型由平台统一决定。

## 与专业开发的边界

编码空间面向"轻前端 + 立即可见"。重型工程(多服务、编译链、版本管理)更适合让 AI 在对话中用命令行工具操作,或接入[外部引擎](../agents/external-engines.md)(如 Claude Code)。
