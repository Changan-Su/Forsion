# 商店

商店是 Forsion 生态的门面:别人打磨好的能力,你一键装上。

## 四个分类

| 分类 | 里面有什么 |
|------|-----------|
| **技能** | 给 AI 的[做事说明书](../agents/skills.md) |
| **插件** | [桌面插件与引擎插件](plugins.md):界面能力与 AI 工具。现成的 [Agent(代理)](../agents/overview.md)和新的[功能空间(Space)](../spaces/overview.md)也列在这一类,卡片上标着各自的类型 |
| **主题** | [外观主题包](themes.md),装完在 设置 → 外观 里选用 |
| **网站应用** | 别人发布的网页应用,点开即用,不用安装 |

## 安装与更新

- 详情页分「内容介绍」「评论」「版本」三栏:看介绍、截图与依赖,一键安装;也可以挑一个历史版本安装;
- 每个条目标着支持的平台和 Forsion 版本要求,首页可以按标签筛、勾「只看适配当前版本」;不适配的装不上,下载前就会拦下;
- 同名的条目可以有好几个,靠作者、介绍和条目 ID(详情页可复制)区分;
- 插件按真实类型自动装到正确位置 —— 桌面插件和引擎插件住在不同地方,你不用操心装错;
- 安装完不会把你拽去设置页;要配置的话,在插件详情页点「打开设置」;
- 「可更新」页集中列出已装内容的可用更新;
- 上架内容经过审核,你装到的始终是**过审版本**,上游仓库事后的改动不会悄悄进你的机器。

## 网站应用

「网站应用」这一类和其他几类不一样:它不往你机器上装东西,点开就在应用内的浏览器里跑。这些应用来自别人在[编码空间](../spaces/coding.md)里发布的作品,填一句简介申请上架、平台审核通过后出现在这里。

## 投稿

做了个好东西?商店内直接**投稿**:提交你的 GitHub 仓库,通过审核后上架,全体用户可见。

投稿时可以写标签、长描述、支持的平台和 Forsion 版本范围。登录后可以在评论区评论和回复;新评论会发到作者的收件箱,作者可以关掉这类消息。

在聊天里也可以直接让 Tangu 帮你在商店里找插件,它给出的是真实条目的卡片,装不装由你在卡片上决定。

网页应用走另一条路——在你自己的发布管理里申请上架,见[编码空间与发布](../spaces/coding.md)。
