# Forsion 更新日志

## 2.8.0 (2026-08-19)

**笔记有画布模式了。** 顶栏那颗双段胶囊一点,同一篇笔记就从文档变成白板:

- 正文按卡片摆到画布上,拖动、缩放、双击空白建新卡;Tab / 回车 / 卡片侧边的 ⊕ 都能接着建
- **思维导图式连接**:把一张卡拖到另一张卡的边缘就认亲 —— 左右缘=子卡片,上下缘=兄弟,松手自动排进队列;关系线可以点中删掉,工具栏的箭头也能直接指定父子
- 白板元素:矩形 / 椭圆 / 文本 / Frame / 自由笔,四角拖着改尺寸,框选、右键菜单、连线一应俱全
- **还是同一个 .md 文件**,不新建文件类型;文档模式下看到的就是普通笔记,两边随时切,撤销是同一条时间线
- ⚠️ 画布笔记用了新的落盘标记,**请把手机 App 一并升到 2.8.0**,否则旧版本会在正文里看到多余的注释行

**AI 给的计划可以先看后批**:计划卡三态 —— 批准 / 编辑后批准 / 打回。改两句再放行,不用推倒重来

**审批规则可以自己写**:除只读 / 自动编辑 / 全自动外新增「自定义」档,按工具与路径写规则;每次弹审批都会说明**这次为什么问你**(是你的规则命中,还是写到了工作区外)

**会话可以多标签打开**:像文件一样在一个窗口里并排开几个对话;在新标签里开东西就开在这个标签,不再把主聊天顶掉

**AI 能翻旧对话的内容了**:2.7.9 只能找到是哪个会话,现在能检索到会话里说过什么

**代码检查点回退**:AI 改崩了可以回到某个时刻的现场(是回到那一刻,不是撤销一步)

**模型菜单改成拖动条**:思考档位像 ChatGPT 那样拖着选,不用再翻二级菜单

**应用市场改版**:从资源目录变成发现式商店,插件与应用合并为一个品类

**插件能力开放**:插件可以往编辑器里插自己的功能(已移植 obsidian-latex-suite —— 数学公式速记)、可以只读读取你的笔记库、支持中英双语

**编辑器补齐**(对齐 AFFiNE):斜杠菜单、页内查找、块选区、列表折叠、代码块工具条、拖拽落点提示、链接卡片

**段落 Tab = 缩进**:Tab / Shift+Tab 调段落缩进档位(不再转成列表),缩进的子树跟着整体移动

**看得见花了多少**:成本闸与自动压缩提示、Context 视图(窗口来源 / 注入段分解 / 指令文件清单)、思考档位可见

**手机端**:侧栏露边圆角适配;抽屉露边加宽、内容字号上一档

- **安全修复**:分享出去的笔记页可能把 frontmatter 当正文公开(画布笔记连坐标一起露)—— 只在 CRLF 换行的文件上发生
- 修:开机还原到笔记时,画布模式胶囊不显示
- 修:窄栏下最后一条消息被悬浮输入卡压住
- 修:侧栏对话的引用芯片、空状态与宽度记忆
- 白板换引擎(zsviczian fork):线宽 5 档、紧凑面板、自定义笔

## 2.7.9 (2026-08-13)

- **修:笔记标题折叠「一折到底」** —— 折叠本该停在下一个同级标题,实际常把后面整篇都收走。根因是躺在段落中间的标题对折叠是隐形的(编辑器里回车=块内换行),现在按行找边界,折叠范围与 Obsidian 一致
- **修:标题行拖不动了** —— 折叠箭头正好压在拖拽手柄上,点手柄变成折叠。箭头改由左侧栏布局排位,与手柄不再重叠
- **修:多设备同时在线编辑会卡输入法、吞掉刚打的字** —— 另一台设备(或 AI、Obsidian)一存盘,本机正在输入的编辑器会被整页重挂,输入法候选框跟着消失、还没落盘的字一起蒸发。现在外部改动会等你停手再合并,合并期间也不会反过来覆盖对方的改动
- **修:手机 App 上额度加载失败、个人中心点了跳不过去**
- **手机浏览器网页版补齐账号面**:点头像能看到剩余额度、用重置卡;个人中心与购买页在同一标签内打开(此前点了毫无反应),登录态自动带过去,不用重新登录
- **修:网页版点「升级会员」只是把应用重载一遍** —— 购买页没被正确转发
- **丝滑光标改为默认关闭**:此前是默认开启,现在需要到设置里自行打开(升级后手感会变回系统原生光标,这是有意调整)
- **修:iOS 网页版软键盘弹出时光标画在错误位置** —— 触屏且键盘占屏期间交还给系统原生光标,键盘收起后再接管
- **AI 能翻你们过去的对话了**:新增会话检索,问「我们上次聊的那个方案」不再回答「看不到会话列表」;检索到的会话在聊天里就是可点击的链接,点开直接续上
- 修:编程预设里那些「用到再加载」的工具(联网搜索、读会话、笔记读写等)实际一律加载失败

- **把侧栏的笔记拖进正文 = 插入引用**:笔记落成 `[[链接]]`,图片 / PDF / 附件落成 `![[嵌入]]`

- **应用市场**:列表与详情加载时是骨架屏;「可更新」页在扫描时如实显示扫描中,不再先闪一下"全部最新"
- 修:换账号登录后,工作区里会先看到上一位账号的目录树
- 修:云端笔记首屏图片偶发加载不出来(要手动刷新才好)
- 修:后台连接启动失败时整个会话静默失联 —— 现在会自动重试三次,仍失败会明确告诉你
- **安全**:笔记里的链接预览改为只抓公网地址(此前可被诱导去请求内网),并加了超时与体积上限,超大页面不再把预览卡住
- 取消会员的接口此前必定报错(后端已修,不用更新客户端也已生效)

## 2.7.7 (2026-08-05)

- **修:文件图标(尤其 md)时不时消失**,列表里和笔记标题上一起没 —— 两个原因都治了:图标数据拉取失败后不再一直空着(自动重试);触屏点过文件夹 / 带子笔记的行之后图标被「悬停换箭头」规则永久藏住(触屏不再换)
- **修:手机上 ⋯ 菜单里点头像没反应** —— 移动端此前缺账号接口,现在点开是完整的账号菜单(额度剩余 / 重置卡 / 邀请 / 用户中心 / 登出)
- **手机界面大改版(Obsidian 风)**:
  - 顶栏极简:只剩左右侧栏开关、**标签页切换**(带数量,点开列表可切可关可新建)和 ⋯

  - 笔记封面图**通铺到屏幕边**,正文左右留白减半

- **笔记改名 / 移动后,全库 `[[引用]]` 自动跟随**(桌面端,含云端笔记库):改名、移动、整个文件夹改名 / 移动都会把引用它的笔记改写到位;重名歧义时自动补全路径,别名与锚点原样保留;代码块里的内容不动

## 2.7.4 (2026-07-31)

> 内容与先前发出的 2.7.4-beta.1 完全相同,已装测试版的直接升上来即可。

- **仪表盘(新)**:一种新的笔记 —— 24 列网格里自由摆卡片,一张卡能装笔记里的任何东西(正文、图片、嵌入的笔记 / 多维表 / 白板),外加时钟、天气、网页三种功能卡。摆完可以「锁定」成浏览模式(不能拖不能改字,但链接照点、时钟照走)。它本身仍是一份普通笔记,搜索、双链、云同步、Obsidian 打开全部照常
- **白板大改**:可以选**有限纸张**(A4/A5/B4/B5 + 纵横)并且画不出纸外;**多页文档** —— 页带首尾各有一颗「＋ 新建页面」,上下排或左右排随时切(切的时候内容跟着页一起搬);**网格**横线竖线各自开关、各自间距、浓淡可调;**紧凑面板**(工具栏收成底部一条横排)。另修好落点偏移、平移时纸张漂移、贴着纸边推会闪
- **自动化**:笔记里可以插一颗**按钮**,点一下就跑你预先配好的规则;新增「手动(按钮)」触发档;多维表**内容变化**也能当触发条件,动作里可以**加一行 / 改一行**
- **聊天里的自动化建议**:聊到值得自动化的事情时,回复末尾会出现几枚可点的芯片 —— 点了等于你自己把那句话发出去,此刻不会建任何规则
- **笔记编辑器一批**:
  - 折叠标注(callout)交互定版 —— **单击标题行折叠 / 双击看源码**,失焦自动收回;`[!note]` 这类令牌不再常驻露出;左边竖线去掉;标题支持 `##`、`- ` 这类块级写法;展开收起有动画

  - **可停靠工作台**:**左侧「工作会话」、中间对话、右侧「文件 / 目录 / 记忆 / 子聊天」全部纳入工作台**,每个面板都是带**图标 + 名称**、可**自由拖拽、调宽、成组 / 分离、停靠**的独立卡片(拖拽更丝滑);布局自动记忆,重启还原;顶栏「侧栏 / 右栏」按钮整体收起 / 展开;打开「设置 / 引导」时面板自动收起,设置铺满全屏

  - **主题升级为「设计语言 × 配色」双轴**(对齐 Amadeus / LCL):**设计语言**(Lovable 平展纸感 / Soft 柔影浮卡)决定结构(圆角 / 字体 / 浮卡布局);**配色**(奶油 / 珊瑚 / 柔青 / 薰衣草 / 自定义)只决定颜色——二者正交,可自由组合(如「柔青 + 柔影浮卡」)。Soft 语言下侧栏 / 主区成为渐变舞台上的圆角浮卡(角落辉光、柔影、无硬边框)
  - **默认黄金分割布局**:中间对话约占 62%、左右面板各约 19%,更聚焦;面板大小 / 位置仍自动记忆,重启还原
  - 面板 tab **更紧凑圆润**(收窄留白、圆角加大)
  - 明暗 / 扁平 / 玻璃开关在所有 设计语言 × 配色 上一致生效
- 旧主题**自动迁移**:Lovable→奶油、Echo→珊瑚、Qbird→柔青、Dreamer→Soft + 薰衣草;升级后可在 设置 → 主题 自由组合设计语言与配色
- 修复:**个人中心**(账户页)里可编辑卡片在内容过长时会把「保存」按钮顶出视口——文本框改为内部滚动,按钮常驻

## 1.2.0 (2026-06-21)

- 新增「微信远程」:在 设置 → 微信远程 扫码连接你的微信 bot,从微信里直接和 Tangu Agent 对话——
  - 作为一个独立的工作区(Project)出现在侧栏顶部,可折叠展开它下面的会话
  - 微信里可用 `/new` 新建会话、`/list` 列出、`/switch <序号>` 切换、`/help` 帮助;回复「停止」中止任务、「批准 / 拒绝」处理待批操作;有「正在输入」状态
  - Agent 可把工作区里的文件 / 图片直接发回到你的微信(「把这个文件发我微信」)
  - 主界面用于设置 / 连接,可查看与切换「正在连接的会话」
- 新增「浏览器工具」:Agent 可用本地轻量浏览器实时搜索网页并交互(`browser_search` 等),默认 DuckDuckGo,支持 Bing / Google / 百度
- 自定义 Provider 新增「拉取模型」:填了 Base URL / API Key 后一键拉取该端点可用模型列表,搜索勾选即可
- 侧栏改进:微信连接默认置顶;工作区可拖拽调整排序;新增会话搜索;删除以「归档」为主操作(永久删除收进归档区)
- 聊天区新增「划线引用」:选中文字浮出「引用」,作为引用块拼到下一条消息前(类 ChatGPT)
- 顶栏精简:去掉一排状态胶囊(Host / 微信 / 在线 等),只在掉线时提示
- 更顺手:微信来消息、开关后台智能体等变化现在自动呈现,无需手动刷新页面
- ⚠️ 「后台智能体」Historian(历史员)与 Muse(缪斯)仍为**实验性功能,目前极其不稳定**,可能出现卡住、重复触发、消耗异常等问题;默认关闭,请谨慎在非重要工作区试用,正式使用前建议保持关闭

## 1.1.0 (2026-06-18)

- 新增「上下文用量条」:输入框下方实时显示当前模型上下文占用百分比与本会话 token 消耗,一眼看清还剩多少额度
- 新增「压缩上下文」:对话变长时一键(输入栏按钮或 `/compact`)总结后精简续接;接近上限会自动压缩,避免超长报错、长对话也能稳稳继续
- 新增「智能体」(Normal Agent):在 设置 → 智能体 里创建可复用的对话人格(系统提示词 + 模型 + 设置),用 `/agent` 一键切换;也可让 AI 在对话中自己沉淀出新的智能体
- 新增「后台智能体」(默认关闭,在 设置 → 后台智能体 开启并选模型;记录隔离,不出现在会话列表):
  - Historian(历史员):对话进行中自动总结会话标题,并在需要时维护你的长期记忆与日志
  - Muse(缪斯):后台持续思考「现在能为你做点什么」,产出 TODO 清单;可多选任务、选一个会话一键注入并开始执行
- 侧栏新增「后台智能体」入口:进入 Historian / Muse 工作区,查看它们的活动与 TODO
