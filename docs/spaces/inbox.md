# 收件箱

当 AI 开始主动干活([盯任务](../agents/muse.md)、[自动化](automation.md)、后台任务),它的产出需要一个不会被错过的落点。收件箱就是这个落点:**所有 Agent 主动发给你的消息,统一在这里**。

## 会收到什么

- Muse 盯任务的提醒与报告("你要的日程摘要来了");
- 自动化规则的执行结果;
- 后台长任务完成的通知;
- 装好[插件](../customization/plugins.md)之后的引导就绪卡;
- 平台发来的官方通知;
- 任何 Agent 在工作中觉得该告诉你的事。

## 阅读与处理

- 未读消息有醒目标记,空间图标带角标,窗口底部的[状态栏](../getting-started/workspace.md)也会显示未读数;
- 消息正文按笔记规则渲染 —— `[[链接]]`、`![[嵌入]]` 都认,写在消息里的笔记引用直接点得开;
- 点开消息可以**跳到来源** —— 哪条规则、哪个会话产生的,一键回溯;
- 处理完的消息可删除,列表保持干净。

## 转发到通道

某条消息值得立刻知道时,可以把它**转发到通道**,推到手机上的微信 / Telegram / QQ。前提是那个通道已经在设置里配好并启用。

详见[通道:微信 / Telegram / QQ](../chat/channels.md)。

## 官方通知里的奖励

平台发来的官方通知可以**附带奖励**:重置卡、积分、会员时长。

- 带奖励的通知在列表里有 🎁 标记;
- 奖励要**打开通知、点「领取」才入账** —— 只是看到它并不等于领了;
- 通知可以有**有效期**。过期的自动归档:内容还翻得到,但不能再领。

领到的东西去哪儿看、怎么用,见[账号、额度与积分](../reference/account-and-quota.md)。

## 定时提醒

想在某个时刻收到提醒,去[自动化](automation.md)里建一条规则:触发选「每天 / 某一刻 / 每隔多久」,动作选发通知。到点消息就会落进收件箱,需要的话同时推到通道。

## 与系统通知的关系

重要的事同时走系统通知(即时弹出)与收件箱(可回溯的清单)。错过了弹窗没关系,收件箱里都在。哪些事件弹通知,在 设置 → 选项 → 通知 里按事件、按插件分别开关。
